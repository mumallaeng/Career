# Portfolio

This portfolio has been migrated from Hugo to Next.js while preserving all the original content and structure from the master branch.

## Project History

This project started as a [Hugo](https://gohugo.io) website using [GitLab Pages](https://about.gitlab.com/stages-devops-lifecycle/pages/) and has been migrated to [Next.js](https://nextjs.org) for improved performance and modern development experience.

The migration preserves all the original portfolio content including:
- Complete project portfolio with multilingual support (Korean/English)
- Activities and achievements section
- Professional experience and certifications
- Custom layouts and styling

## Getting Started

This is a [Next.js](https://nextjs.org) project. To run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Building and Deployment

The project is configured for deployment on GitLab Pages with static export:

```bash
npm run build
```

This generates a static export in the `out/` directory, which is then deployed via GitLab CI/CD.
