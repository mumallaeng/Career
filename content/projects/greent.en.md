## Tech Stack
- **Hardware**: Arduino, Raspberry Pi
- **Sensors**: Soil moisture sensor, RFID
- **Actuators**: Water pump, stepper motor
- **Communication**: Serial communication
- **Backend**: Python Flask

- Developed automatic watering and access control systems through Arduino, Raspberry Pi, and sensor integration

### Video Monitoring System
- Implemented Raspberry Pi camera video streaming
- Developed stepper motor-based field of view adjustment functionality

### Access Management System
- Integrated RFID recognition-based access control functionality into system control logic

### Backend System Development
- Configured Python-based Flask backend
- Integrated hardware and software through serial communication
- Developed communication system for system controller and GUI integration
