Developed an autonomous driving robot capable of navigating indoor environments by fusing LiDAR and camera sensors.

<!--more-->

## Project Overview
- **Duration**: March 2023 - December 2023
- **Team Composition**: 4 members (2 robotics engineers, 2 AI developers)
- **Role**: Sensor fusion and path planning algorithm development

## Tech Stack
- **Platform**: ROS2 Humble
- **Languages**: Python, C++
- **Sensors**: Velodyne LiDAR, Intel RealSense camera
- **AI/ML**: TensorFlow, OpenCV

## Key Features
1. **SLAM (Simultaneous Localization and Mapping)**
   - LiDAR-based 2D map generation
   - Real-time localization

2. **Object Detection and Avoidance**
   - YOLO-based real-time object detection
   - Dynamic obstacle avoidance algorithms

3. **Path Planning**
   - A* algorithm-based global path planning
   - DWA-based local path planning

## Achievements
- Achieved over 95% navigation success rate in indoor environments
- Won Excellence Award at Robotics Society
- Published 1 related research paper
