## Project Overview
- **Duration**: June 2022 - February 2023
- **Partner Company**: Hyundai Robotics
- **Role**: Motion planning and simulation development

## Tech Stack
- **Platform**: ROS Noetic
- **Languages**: C++, Python
- **Simulator**: Gazebo, RViz
- **Hardware**: UR5e robot arm

## Development Content
1. **URDF Modeling**
   - Implemented accurate kinematic model of robot arm
   - Optimized mesh models for collision detection

2. **MoveIt Configuration**
   - Configured inverse kinematics solver
   - Optimized path planning algorithms
   - Implemented collision detection system

3. **Task Scenarios**
   - Pick & Place task automation
   - Workspace safety verification
   - Real-time trajectory modification features

## Key Achievements
- Achieved over 98% task success rate
- 30% faster task completion time compared to existing systems
- Completed safety certification for industrial application
