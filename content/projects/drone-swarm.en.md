Developed a swarm robotics system that enables multiple drones to collaborate and perform complex missions.

<!--more-->

## Project Overview
- **Duration**: October 2023 - January 2024
- **Team Composition**: 5 members (2 drone hardware, 3 software)
- **Sponsor**: Ministry of SMEs and Startups startup support program

## Tech Stack
- **Platform**: PX4, ROS2
- **Languages**: C++, Python
- **Communication**: MAVLink, UDP
- **Simulation**: Gazebo, AirSim

## Core Features
1. **Distributed Control Algorithm**
   - Leader-follower structure based formation flight
   - Dynamic obstacle avoidance
   - Real-time path replanning

2. **Collaborative Mission Execution**
   - Area exploration and mapping
   - Cargo transport collaboration
   - Emergency response

3. **Communication and Networking**
   - Distributed network topology
   - Signal loss response mechanisms
   - Real-time data synchronization

## Key Achievements
- Successfully controlled up to 8 drones simultaneously
- Achieved 94% mission success rate
- Won Innovation Award at Drone Show Korea 2024
