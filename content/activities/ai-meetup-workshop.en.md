Conducted a workshop at Seoul AI Developer Meetup covering the entire process from ROS2 basics to actual robot control.

<!--more-->

## Workshop Information
- **Event**: Seoul AI Developer Meetup
- **Date**: September 20, 2023, 14:00-18:00
- **Venue**: Gangnam WeWork Shared Office
- **Participants**: 30 people (AI/robot developers, graduate students)

## Workshop Structure
### Part 1: ROS2 Basics (90 minutes)
- ROS2 architecture and core concepts
- Understanding nodes, topics, services, and actions
- Writing simple nodes using Python/C++
- Hands-on: "Hello ROS2" publisher/subscriber

### Part 2: Sensor Data Processing (90 minutes)
- LiDAR and camera data processing methods
- Coordinate transformation using tf2
- Basic theory of sensor fusion
- Hands-on: Virtual sensor data visualization

### Part 3: Robot Control Practice (90 minutes)
- Building TurtleBot3 simulation environment
- Implementing keyboard remote control nodes
- Implementing basic autonomous driving algorithms
- Hands-on: Obstacle avoidance driving

## Preparation Process
### Educational Material Creation
- 130-page PPT slides
- Practice code templates and solutions
- Docker-based development environment package
- Online tutorial site construction

### Hardware Preparation
- Rental of 10 laptops (for practice)
- 2 TurtleBot3 units for demonstration
- Network environment configuration

## Workshop Results
### Participant Feedback
- Satisfaction rating: 4.6/5.0
- "Content directly applicable to work" - Current developer
- "Could easily understand complex ROS2" - Graduate student

### Follow-up Activities
- Workshop materials released as open source (GitHub 500+ stars)
- Additional advanced workshop conducted 3 months later
- Study group formed with 5 participants

## Teaching Experience
Through this workshop, I learned how to easily convey complex technical content. Especially, hands-on education greatly improved participants' understanding.
