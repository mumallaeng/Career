Won 2nd place at the 2022 Open Source Robotics Hackathon by developing a robot system for disaster rescue operations.

<!--more-->

## Hackathon Information
- **Event**: Open Source Robotics Hackathon 2022
- **Organizer**: Korea Robotics Society × NAVER Cloud
- **Duration**: August 13-15, 2022 (48 hours)
- **Teams**: Total 50 teams, 200 participants

## Development Theme
**"Disaster Rescue Robot"**
- Survivor detection in disaster sites like earthquakes and fires
- Remote reconnaissance and situation assessment in hazardous areas
- Real-time communication system with rescue teams

## Team Composition and Role
- **Team Name**: RescueBot
- **Members**: 4 people (2 robotics engineers, 2 software developers)
- **My Role**: Team leader, SLAM and autonomous navigation

## Tech Stack
- **Hardware**: TurtleBot3, additional sensor modules
- **Software**: ROS Melodic, OpenCV, TensorFlow
- **Communication**: WebRTC, Socket.io
- **Cloud**: NAVER Cloud Platform

## Implemented Features
### 1. Autonomous Exploration System
- Real-time mapping based on Gmapping
- Unexplored area priority search algorithm
- Obstacle and hazard avoidance

### 2. Survivor Detection
- YOLO-based human detection
- Vital sign detection using thermal camera
- Help request detection through voice recognition

### 3. Remote Control System
- Web-based real-time control interface
- Robot perspective video streaming
- Two-way voice communication

## Hackathon Process
### Day 1 (13th)
- Idea refinement and tech stack decision
- Hardware setup and basic ROS environment construction
- Team role assignment and development schedule

### Day 2 (14th)
- Intensive development of core functions
- SLAM and autonomous navigation algorithm implementation
- Human detection model training and optimization
- Overnight debugging and performance optimization

### Day 3 (15th)
- Final integration testing and demo preparation
- Presentation materials and demonstration scenario creation
- 10-minute presentation + real-time demo before judges

## Award Results
### Final Ranking: 2nd Place 🥈
- **Prize Money**: 3 million won
- **Special Prize**: NAVER Cloud credits worth 1 million won
- **Follow-up Support**: Startup incubating program participation opportunity

### Judging Evaluation
- **Technical Completeness**: 4.5/5
- **Creativity**: 4.2/5
- **Practicality**: 4.8/5
- **Teamwork**: 4.7/5

## Follow-up Activities
- Patent application based on hackathon results
- Collaboration with fire departments for actual training use
- Open source release for community contribution

Through this hackathon, I learned the ability to quickly implement ideas within limited time and the importance of teamwork.
