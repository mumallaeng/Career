OV7670 카메라 영상에서 녹색 객체를 검출하고, 객체 중심과 화면 중심의 오차로 Pan-Tilt 카메라가 대상을 따라가도록 만든 FPGA 시스템입니다. 영상 입력, 색상 검출, 노이즈 제거, 중심 좌표 계산과 서보 제어를 Basys 3 하나에 통합했고, 조이스틱으로 카메라 방향을 직접 조절하는 수동 모드도 함께 구성했습니다.

## 설계 사양

| 항목 | 설계 내용 |
|:--|:--|
| 카메라 입력 | OV7670, QVGA 320×240, RGB565 |
| VGA 출력 | 640×480 타이밍, RGB444, 픽셀 클록 25 MHz |
| 추적 대상 | 녹색 객체, G ≥ 128, G−R ≥ 40, G−B ≥ 40 |
| 공간 노이즈 제거 | 3×3 이웃 9픽셀 중 5개 이상이 검출되면 마스크 1 |
| 객체 유효 조건 | 프레임 내 검출 픽셀 수 700개 이상 |
| 좌표 안정화 | 객체 중심 좌표에 5프레임 평균 적용 |
| 조이스틱 처리 | 12-bit ADC, 4-sample 이동평균, 변화량 −10~+10 |
| 서보 출력 | SG90 2축, 50 Hz, High 펄스 폭 약 1~2 ms |
| 기계적 동작 범위 | Pan 15°~165°, Tilt 25°~155° |

영상 경로는 OV7670 Capture → Frame Buffer → Green Filter → 3×3 Noise Filter → 경계·중심 계산으로 이어지고, VGA 화면에는 카메라 영상과 Bounding Box를 출력합니다. 자동 모드는 영상에서 계산한 중심 오차를, 수동 모드는 조이스틱 변화량을 서보 제어부에 넘깁니다.

## 담당 작업

- `ctrl_mode_mux`: 자동 모드의 `frame_dx/dy`와 수동 모드의 `joy_dx/dy` 중 하나를 고르고, 자동은 대상 검출이 유효할 때의 `frame_done`, 수동은 `joy_done`에 맞춰 갱신 신호를 함께 전달했습니다.
- `servo_pwm`: 각도 명령을 High count로 바꾸고 20 ms(2,000,000 count) 주기 카운터와 비교해 Pan·Tilt PWM을 만들었습니다. 목표 High count는 주기 경계에서 반영해 출력 중인 펄스 폭이 중간에 바뀌지 않게 했습니다.
- `servo_top` 통합: 입력 선택, 축별 각도 제어(5/16°/count 이득, 1회 최대 ±20°, Pan 15°~165°·Tilt 25°~155° 제한), 2채널 PWM을 하나로 묶었습니다.

통합 시험에서 객체를 보정할수록 카메라가 반대로 움직이는 문제가 나왔습니다. 영상 좌표의 보정 방향과 브래킷에 장착된 서보의 회전 방향이 반대였기 때문이며, 각도 변화량의 부호를 반전해 정상 추적하도록 고쳤습니다. 조명에 따른 색상 임계값 자동 조정, 객체 미검출 시 재탐색, 오차 크기에 따른 가변 이득은 향후 개선 항목으로 남겼습니다.
