
### 과제 요구사항
- 컴퓨터 시스템 및 네트워크 보안 장비가 초기화된 상태에서 시작
- 장비 점검 시간을 통해 선수는 충분히 장비를 점검하고, 이상 발견 시 심사위원에게 보고하여 적절한 조치를 받음
- 개인이 지참한 키보드, 마우스의 경우 매크로 및 저장 기능이 없어야 함

### 주의 사항
#### 시행 중
- 각 과제는 기본 5시간으로 진행하며, 심사위원 합의하에 20% 범위에서 조정 가능
- 선수는 각 장비의 오류로 인해 각 설정 값이 지워질 수 있으므로 수시로 저장 필요
- 각 과제는 종료 후 바로 채점 시행
- **1과제 후 절대 시스템을 초기화하지 않음. 1과제의 설정에 2과제 문제를 해결해야 함**

#### 시행 후
- 모든 채점은 채점기준표에 의거하여 채점하며, 심사위원 합의 하에 복수 답안이 존재할 수 있음
- 심사위원의 합의가 이루어지지 않을 경우, 채점기준표 대로 채점함을 원칙으로 함
