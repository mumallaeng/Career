## Pyodide

Python을 WebAssembly로 컴파일하여 브라우저에서 실행 가능하게 하는 인터프리터입니다. \
컨트리뷰션 아카데미에서 RustPython에 기여한 이후 혼자서 오픈소스에 기여해보고 싶어 찾던 중, 이전에 [DIY/CodeB](codeb.mdx)에서 Pyodide를 사용했던 경험이 떠올라 기여를 시작했습니다.

### Pull Request: [Fix repr_shorten and Add shorten #3178](https://github.com/pyodide/pyodide/pull/3178)
- **기간**: 2022.10.12 ~ 2022.10.22 (11일, 병합)

#### 해결한 문제

1. **`repr_shorten` 함수의 버그** — `split` 파라미터가 제대로 검증되지 않아, 값이 문자열 길이의 절반을 초과하면 `"5678..5678"` 같은 비정상적인 출력이 발생했습니다.
2. **문서화 부족** — 함수 사용 예제가 없어 개발자들이 사용법을 이해하기 어려웠습니다.

#### 구현 내용

```python
split = min(split, limit//2)
```
- `split` 파라미터를 제한해 항상 접두사와 접미사가 구분자와 함께 포함되도록 보장
- 범용 텍스트 단축 유틸리티 `shorten()` 함수를 `repr_shorten`의 일반화 버전으로 추가
- 두 함수 모두에 상세한 docstring 예제를 추가하고 changelog에 변경 사항을 문서화

#### 느낀 점
- Pyodide는 PR에서 changelog 작성이 필요했습니다. 평소 사용하며 체계적인 문서화가 인상 깊었는데, 직접 기여하면서 그 이유를 느낄 수 있었습니다.
- 직접 사용해본 오픈소스 프로젝트에 기여하니 더 의미있고 재미있었습니다.

## pyre

[youknowone/pyre](https://github.com/youknowone/pyre)는 RustPython 메인테이너 Jeong, YunWon(youknowone)님이 새로 시작한, 빠르고 CPython 호환성을 목표로 하는 Python 인터프리터 프로젝트입니다. \
RustPython에서의 인연을 이어 2026년 8월에 기여했습니다.

| PR | 날짜 | 내용 |
|:--|:--|:--|

## Vivado 생태계 기여

과정에서 실제로 사용하는 Vivado/Vitis 툴체인과 맞닿아 있는 오픈소스 프로젝트에도 이슈·PR을 보내고 있습니다.

- **[Xilinx/XilinxTclStore](https://github.com/Xilinx/XilinxTclStore) — [PR #846](https://github.com/Xilinx/XilinxTclStore/pull/846)** (2026.08.23, 리뷰 중) \
  Tcl 8.6의 `clock`·`msgcat` 네임스페이스 충돌로 Vivado에서 junit tclapp 설치가 sandbox 환경에서 실패하는 문제를 수정했습니다.
- **[ichi4096/vivado-on-silicon-mac](https://github.com/ichi4096/vivado-on-silicon-mac) — [PR #82](https://github.com/ichi4096/vivado-on-silicon-mac/pull/82)** (2026.04.13, closed) \
  Apple Silicon(M1/M2/M3) Mac에 Vivado를 설치하는 스크립트에 Vivado 2025.2 지원을 추가했습니다.

## 이슈 리포트

- **[microsoft/vscode-python](https://github.com/microsoft/vscode-python) — [Issue #26039](https://github.com/microsoft/vscode-python/issues/26039)** (2026.07.12, open) \
  내장 함수(`int` 등)를 변수명으로 덮어쓰면 `pythonrc.py`의 PS1 설정이 깨지면서 터미널 REPL의 `>>>` 프롬프트가 사라지는 문제를 리포트했습니다.
