## 1. 문서 개요

본 문서는 돌봄 챗봇 시스템(Dolbom Chatbot System)의  
소프트웨어 요구사항 명세서(SRS: Software Requirements Specification)로서  
기능 및 비기능 요구사항을 정의하고 명세함.  
IEEE SRS 형식을 기준으로 작성됨.

---

## 2. 시스템 개요

본 시스템은 사용자와 감정 기반으로 상호작용하는 AI 돌봄 서비스를 제공함.

### 주요 기능
- 로그인, 회원가입  
- 실시간 채팅 및 감정 분석  
- 사용자 상태 모니터링  
- 펫(Dolbom) 설정 및 훈련  
- 제스처/음성 기반 상호작용  
- 사용자 UI 설정 저장

### 시스템 구성요소

| 항목 | 내용 |
|------|------|
| GUI | PyQt5 |
| 통신 | TCP(9000), UDP(5005/Video Stream, 5010/Audio Stream, 9100/Gesture Event) |
| DB | MySQL (dolbom_chatbot) |
| 감정 분석 | 텍스트/음성/표정 기반 3요소 |
| 음성 입출력 | Whisper(STT), gTTS(TTS) |
| 챗봇 응답 | GPT4All 사용하다가 성능에 따라서 OpenAI API로 전환 |

## 3. 기능 요구사항

### 3.1 사용자 인증

| 기능 | 설명 |
|------|------|
| 로그인 | 이메일/비밀번호 입력, 성공 시 토큰 및 ID 반환 |
| 회원가입 | 이름, 닉네임, 이메일, 비밀번호 등록 |

---

### 3.2 사용자 인터페이스

| 기능 | 설명 |
|------|------|
| 메인 화면 | 로그인 이후 탭 형태 화면 표시 |
| 건강 상태 패널 | 감정 분석 결과 표시 |
| Dolbom 상태 패널 | 연동 상태, 펫 성격, 관계 정보 등 |

---

### 3.3 채팅 및 감정 기능

| 기능 | 설명 |
|------|------|
| 실시간 채팅 | 대화 유지, 감정 표현 포함 |
| 최근 대화 확인 | 최근 메시지 내용 확인 가능 |
| 감정 분석 | 얼굴, 음성, 텍스트 기반 분석 |
| 이모티콘 출력 | 감정에 맞는 표정 이모티콘 표시 |

---

### 3.4 펫 설정 및 훈련

| 기능 | 설명 |
|------|------|
| 펫 성격 설정 | 말투, 성격, 특이사항 설정 및 조회 |
| 펫 훈련 기능 | 명령어-제스처 매핑 저장 및 적용 |

---

### 3.5 제스처/음성 기능

| 기능 | 설명 |
|------|------|
| 제스처 인식 | 제스처 이벤트 처리 및 반응 출력 |
| 음성 입력 | 마이크 기반 STT (Whisper 연동) |
| 음성 출력 | 텍스트 기반 TTS (gTTS 연동) |
| 카메라 제어 | ON/OFF 제어 기능 포함 |

---

### 3.6 사용자 설정

| 기능 | 설명 |
|------|------|
| 텍스트 크기 조절 | 설정 패널에서 폰트 크기 조절 가능 |
| 설정 저장 | 서버에 저장 및 자동 적용 |

---
