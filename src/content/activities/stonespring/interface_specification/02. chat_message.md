# 채팅 메시지 전송 명세서

---

## 개요

| 항목 | 내용 |
|------|------|
| 구분 | 채팅 메시지 |
| 목적 | 사용자 입력 메시지 전송 및 펫 응답 수신 + 저장 처리 |
| 데이터 형식 | JSON |
| 사용 프로토콜 | TCP / UDP  &#124;&#124;  CoAP / MQTT |

---

## 공통 메시지 구조

```json
{
  "command": "send_message",
  "payload": {
    "userId": 1,
    "messageId": 10,
    "message": "괜찮을까?",
    "timestamp": "2025-03-23 14:25:00",
    "videoId": 101,
    "videoPath": "/video/101.mp4",
    "videoStartTimestamp": "00:00:05.000",
    "videoEndTimestamp": "00:00:08.500",
    "voiceId": 201,
    "voicePath": "/voice/201.wav",
    "voiceStartTimestamp": "00:00:05.000",
    "voiceEndTimestamp": "00:00:08.500"
  }
}
````

---

## 요청 명세

### 공통 필드

| 필드명     | 타입     | 필수 | 설명                  | 매핑 DB 컬럼 |
| ------- | ------ | -- | ------------------- | -------- |
| command | STRING | 예  | `"send_message"` 명령 | -        |

---

### payload 필드

| 필드명                 | 타입       | 필수 | 설명                       | 매핑 DB 컬럼              |
| ------------------- | -------- | -- | ------------------------ | --------------------- |
| userId              | INT      | 예  | 사용자 고유 ID                | user_id               |
| messageId           | INT      | 예  | 채팅 메시지 고유 ID             | message_id            |
| message             | STRING   | 예  | 사용자 입력 메시지               | message               |
| timestamp           | DATETIME | 예  | 메시지 전송 시간                | timestamp             |
| videoId             | INT      | 옵션 | 동영상 ID                   | video_id              |
| videoPath           | STRING   | 옵션 | 동영상 경로                   | video_path            |
| videoStartTimestamp | STRING   | 옵션 | 동영상 시작 지점 (상대 timestamp) | video_start_timestamp |
| videoEndTimestamp   | STRING   | 옵션 | 동영상 종료 지점                | video_end_timestamp   |
| voiceId             | INT      | 옵션 | 음성 ID                    | voice_id              |
| voicePath           | STRING   | 옵션 | 음성 파일 경로                 | voice_path            |
| voiceStartTimestamp | STRING   | 옵션 | 음성 시작 지점                 | voice_start_timestamp |
| voiceEndTimestamp   | STRING   | 옵션 | 음성 종료 지점                 | voice_end_timestamp   |

---

## 응답 명세

```json
{
  "resultCode": 1000,
  "resultMsg": "SUCCESS",
  "data": {
    "chatId": 3001,
    "eId": 5,
    "petEmotion": "기분 좋아요",
    "replyMessage": "너무 잘하고 있어!"
  }
}
```

---

### data 필드

| 필드명          | 타입     | 설명           | 매핑 DB 컬럼      |
| ------------ | ------ | ------------ | ------------- |
| chatId       | INT    | 채팅 세트 ID     | chat_id       |
| eId          | INT    | 펫 감정 ID      | e_id          |
| petEmotion   | STRING | 분석된 펫 감정 텍스트 | pet_emotion   |
| replyMessage | STRING | 펫의 응답 메시지    | reply_message |

---

## 응답 코드 정의

| 코드   | 메시지             | 설명                |
| ---- | --------------- | ----------------- |
| 1000 | SUCCESS         | 채팅 저장 및 응답 성공     |
| 2001 | USER_NOT_FOUND  | 사용자 ID 없음         |
| 2002 | INVALID_MESSAGE | 메시지 누락 또는 유효하지 않음 |
| 5000 | INTERNAL_ERROR  | 서버 내부 오류          |

---

## 프로토콜별 전송 방식 예시

### TCP / UDP

* JSON 메시지 그대로 전송
* 메시지 구분 방식: 개행 문자(`\n`) 또는 길이 prefix

---

### MQTT

| 항목      | 값            |
| ------- | ------------ |
| Topic   | chat/message |
| Payload | 위 JSON 메시지   |

---

### CoAP

| 항목      | 값                        |
| ------- | ------------------------ |
| Method  | POST                     |
| URI     | coap://host/chat/message |
| Payload | 위 JSON 메시지               |
