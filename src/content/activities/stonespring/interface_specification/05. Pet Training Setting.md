# 사용자 정의 펫 응답 훈련 설정 명세서

---

## 개요

| 항목 | 내용 |
|------|------|
| 구분 | 사용자 정의 펫 응답 훈련 설정 |
| 목적 | 명령어, 키워드, 제스처 기반으로 펫 응답 행동 훈련 설정 및 조회 |
| 데이터 형식 | JSON |
| 사용 프로토콜 | TCP / UDP / CoAP / MQTT |

---

## 공통 메시지 구조

```json
{
  "command": "set_response",
  "payload": {
    "userId": 1,
    "trainingText": "날씨",
    "keywordText": "날씨, 하늘",
    "gestureVideoPath": "/gesture/weather.mp4",
    "gestureRecognitionId": 3101,
    "recognizedGesture": "오늘의 날씨 데이터 가져오기"
  }
}
````

또는

```json
{
  "command": "get_response",
  "payload": {
    "userId": 1
  }
}
```

---

## 요청 명세

### 공통 필드

| 필드명     | 타입     | 필수 | 설명                                   | 매핑 DB 컬럼 |
| ------- | ------ | -- | ------------------------------------ | -------- |
| command | STRING | 예  | `"set_response"` 또는 `"get_response"` | -        |

---

### payload – set_response

| 필드명                  | 타입     | 필수 | 설명           | 매핑 DB 컬럼               |
| -------------------- | ------ | -- | ------------ | ---------------------- |
| userId               | INT    | 예  | 사용자 고유 ID    | user_id                |
| trainingText         | STRING | 예  | 훈련시킬 명령어     | training_text          |
| keywordText          | STRING | 예  | 관련 키워드       | keyword_text           |
| gestureVideoPath     | STRING | 예  | 제스처 영상 경로    | gesture_video_path     |
| gestureRecognitionId | INT    | 예  | 제스처 인식 결과 ID | gesture_recognition_id |
| recognizedGesture    | STRING | 예  | 인식된 제스처 설명   | recognized_gesture     |

---

### payload – get_response

| 필드명    | 타입  | 필수 | 설명        | 매핑 DB 컬럼 |
| ------ | --- | -- | --------- | -------- |
| userId | INT | 예  | 사용자 고유 ID | user_id  |

---

## 응답 명세

```json
{
  "resultCode": 1000,
  "resultMsg": "SUCCESS",
  "data": {
    "responseSettingId": 7001,
    "trainingText": "날씨",
    "keywordText": "날씨, 하늘",
    "gestureVideoPath": "/gesture/weather.mp4",
    "gestureRecognitionId": 3101,
    "recognizedGesture": "오늘의 날씨 데이터 가져오기"
  }
}
```

---

### data 필드

| 필드명                  | 타입     | 설명           | 매핑 DB 컬럼               |
| -------------------- | ------ | ------------ | ---------------------- |
| responseSettingId    | INT    | 훈련 설정 고유 ID  | training_setting_id    |
| trainingText         | STRING | 설정된 명령어      | training_text          |
| keywordText          | STRING | 설정된 키워드      | keyword_text           |
| gestureVideoPath     | STRING | 제스처 영상 경로    | gesture_video_path     |
| gestureRecognitionId | INT    | 제스처 인식 결과 ID | gesture_recognition_id |
| recognizedGesture    | STRING | 인식된 제스처 설명   | recognized_gesture     |

---

## 응답 코드 정의

| 코드   | 메시지            | 설명                |
| ---- | -------------- | ----------------- |
| 1000 | SUCCESS        | 처리 성공             |
| 2001 | USER_NOT_FOUND | 사용자 ID 없음         |
| 2002 | INVALID_INPUT  | 필수 항목 누락 또는 형식 오류 |
| 5000 | INTERNAL_ERROR | 서버 내부 오류          |

---

## 프로토콜별 전송 방식 예시

### TCP / UDP

* JSON 메시지 전송 (길이 기반 또는 개행 구분)

---

### MQTT

| 항목      | 값            |
| ------- | ------------ |
| Topic   | pet/training |
| Payload | 위 JSON 메시지   |

---

### CoAP

| 항목      | 값                        |
| ------- | ------------------------ |
| Method  | POST                     |
| URI     | coap://host/pet/training |
| Payload | 위 JSON 메시지               |
