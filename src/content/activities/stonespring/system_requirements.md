| 기능 | 설명 |
|------|------|
| 로그인 | 사용자가 이메일/비밀번호 입력 → 성공 시 인증 토큰 및 ID 반환 |
| 회원가입 | 사용자가 이름, 닉네임, 이메일, 비밀번호 입력하여 등록 |
| 감정 상태 | 사용자의 표정·음성·텍스트를 분석하여 감정 상태를 표시 |
| Dolbom 상태 | 펫(Dolbom)의 연동 여부, 성격 설정, 사용자와의 관계 설정 |
| 실시간 채팅 | 사용자와 펫이 실시간으로 대화 가능, 감정 표현 포함 |
| 최근 대화 확인 | 사용자가 이전 채팅 내용을 확인 가능 |
| 감정 분석 | 사용자의 얼굴, 음성, 텍스트를 기반으로 다중 감정 분석 |
| 펫 성격 설정 | 사용자가 펫의 말투, 성격, 특이사항 등을 직접 설정 가능 |
| 펫 훈련 기능 | 사용자가 특정 텍스트 또는 제스처에 반응하도록 펫을 훈련 |
| 제스처 인식 | 사용자가 제스처 수행 → 인식 시 펫이 매핑된 반응 출력 |
| 음성 입력 | 사용자의 마이크 입력을 통해 음성 인식 |
| 음성 출력 | 펫이 대답할 때 텍스트를 음성으로 변환하여 출력 |
| 카메라 제어 | 카메라 ON/OFF 기능으로 사용자 표정 입력 가능 여부 제어 |
| 설정 저장 | 사용자 설정을 저장하고 반영 |
