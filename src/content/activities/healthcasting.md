프로젝트 팀장으로서 검색 트렌드 데이터를 활용한 건강 경보 시스템을 개발했습니다.

<!--more-->

## 프로젝트 개요
- **기간**: 2024.12.12 ~ 2025.01.03 (3주)
- **역할**: 프로젝트 팀장 및 트렌드 데이터 담당
- **목표**: 검색 트렌드 기반 예방적 건강 경보 시스템 구축

## 기술 스택
- **데이터 수집**: pytrends, Naver API, 기상청 API
- **분석**: Python, Pandas, 시계열 분석
- **시각화**: Matplotlib, Seaborn
- **언어**: Python
- **데이터 처리**: EDA, 상관 분석

## 주요 담당 업무

### 검색 트렌드 기반 건강 경보 시스템 설계
- Google/Naver 검색 트렌드 기반 건강 경보 시스템 설계
- pytrends, Naver API를 활용해 질병/건강 관련 키워드 검색량 수집
- 특정 질병 관련 검색 급등 시 건강 주의 알림 생성 로직 설계

### 외부 데이터 연계 및 분석
- 기상청 날씨 데이터와 검색 트렌드 데이터를 수집 및 통합
- 질병 키워드와 기상 조건 간의 연관성 분석을 위한 시계열 처리 수행

### EDA 기반 상관 분석
- 검색 트렌드와 기상 데이터 간의 상관관계 분석
- 질병별 검색 패턴과 환경 요인의 연관성 탐구

### 프로젝트 관리
- 프로젝트 파일 구조 표준화 및 DB 관련 함수 통합
- 구글 트렌드 데이터 수집 및 질병 트렌드 변화 분석

## 핵심 성과
- 검색 트렌드를 통한 질병 유행 예측 모델 개발
- 기상 데이터와 건강 키워드 검색량 간의 상관관계 발견
- 예방적 건강 관리를 위한 조기 경보 시스템 구축
- 데이터 기반 건강 정보 제공 플랫폼 설계
