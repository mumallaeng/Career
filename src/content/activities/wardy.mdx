> *[컨소시엄] 온디바이스AI 시스템반도체 설계 2기* 교육과정의 On-Device AI 팀 프로젝트입니다. \
> 과정 소개: [경기도 팹리스 아카데미 · 온디바이스AI 시스템반도체 설계 2기](korcham-ondevice-ai-semiconductor.mdx) \
> 다른 과정 프로젝트: [미니 프로젝트 모음](korcham-ondevice-ai-mini-projects.mdx)

보호자가 자리를 비운 돌봄 공백 시간에 USB 카메라와 엣지 디바이스만으로 낙상 의심·장시간 정지·위험물 근접을 감지하고, 확인이 필요한 상황을 사건과 증거 자료로 정리해 보여주는 가정용 안전 모니터링 플랫폼입니다. 영상은 클라우드로 보내지 않고 Jetson 안에서 추론과 저장을 마칩니다.

## 프로젝트 정보

| 항목 | 내용 |
|:--|:--|
| 기간 | 2026.08.05 ~ 2026.08.19 |
| 팀 | 지켜조(9조) 3인: 김연우(M-02~M-04), 박지원(M-05 위험물 탐지), 조정민(M-01 사람 탐지) |
| 실행 환경 | Jetson Orin Nano, USB webcam, Windows·macOS·mobile browser |
| 원칙 | 의료 진단 없이 '의심 상황'과 '확인 필요' 정보를 제공하고 자료는 로컬 기기에 저장 |

## 파이프라인

| 모듈 | 내용 |
|:--|:--|
| M-01 사람 탐지 | YOLO11n, TensorRT 추론 |
| M-02 익명 추적 | Kalman Filter, IoU Gate, Hungarian assignment로 익명 `track_id` 부여 |
| M-03 자세 추정 | RTMPose-M, COCO-17 keypoint 기반 자세 분류 |
| M-04 낙상 감지 | 20 frame(2초) 관절 시퀀스를 입력받는 TemporalFallGRU와 standing→lying 급전환 Fast Path |
| M-05 위험물 탐지 | YOLO11n 4 class(Scissors·Knife·Cutter·Syringe), 사람과의 근접 판단 |
| M-06 일일 요약 | Ollama 로컬 LLM, JSON Schema 검증과 deterministic fallback |

C++ Edge Service가 GStreamer로 프레임을 받아 M-01을 실행하고, Unix domain socket으로 Python worker에 넘겨 M-02~M-04를 이어서 처리합니다. 결과는 이벤트·돌봄 상태 계약으로 정규화해 SQLite에 저장하고, HTTPS·WebSocket·WebRTC(WHEP)로 browser UI에 전달합니다.

## 담당 작업

- M-02 익명 추적: Kalman Filter·IoU Gate·Hungarian assignment로 사람마다 익명 `track_id`를 부여했습니다.
- M-03 자세 추정: RTMPose-M으로 COCO-17 keypoint를 추정하고 자세를 분류했습니다.
- M-04 낙상 감지: 20 frame(2초) 관절 시퀀스를 받는 TemporalFallGRU와 standing→lying 급전환 Fast Path로 낙상을 판단했습니다.

## 결과

| 모듈 | 검증 결과 |
|:--|:--|
| M-01 | Test Set 기준 Precision 0.925, Recall 0.869, mAP50 0.945 |
| M-04 | Fast Path와 GRU 조합으로 급전환 낙상을 즉시 감지, threshold 하한으로 오탐 억제 |
| M-05 | mAP@0.5 83.5%, Jetson·C270 실환경에서 Scissors·Cutter·Syringe 검출 확인(Knife는 실환경 미검증) |
| M-06 | 검증된 한국어 요약을 UI에 반환, 오류 시 fallback 동작 확인 |

단일 카메라와 약 10일의 범위에서 낙상 감지부터 사건 확인까지의 흐름을 구현했습니다. 다중 카메라, 외부 알림, 클라우드 원격 접근, 장시간 무인 운용 검증은 향후 개선 항목으로 남겼습니다.
