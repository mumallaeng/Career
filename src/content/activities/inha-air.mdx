인하공업 전문대학 컴퓨터시스템과 2학년 1학기 [Java 프로그래밍 응용] 과제 팀 프로젝트로, 
항공 예매 시스템에서 항공 예매 기능을 주로 구현했습니다.

## 담당 작업

- 항공권 예매 과정 중 예매 정보 입력, 로그인, 회원가입, 아이디·비밀번호 찾기 UI를 맡았습니다.
- 정규표현식 기반 입력값 검증과 예외 상황 분기를 구현했습니다.
- 탑승일 선택 달력, 출발지·도착지 선택, 탑승 인원 입력 흐름을 Java Swing 화면으로 구성했습니다.
- 팀원들이 만든 예약·결제·관리자 기능과 이어질 수 있도록 화면 전환과 데이터 전달 흐름을 맞췄습니다.

## 프로젝트 개요
**기간**: 2021.05.13 ~ 2021.07.15 (2개월)

### 목표
#### 사용자
  - 간편한 항공 스케줄 조회
  - 직관적인 UI로 탑승일 선택 지원
  - 빠르고 편리한 항공권 예약·발권 시스템
#### 관리자
  - 항공편 스케줄 관리
  - 예약 현황 조회 및 관리

### 사용 도구
- **언어**: Java
- **GUI**: Java Swing
- **데이터베이스**: MySQL, SQLite
- **버전관리**: Git, GitHub
- **협업**: Discord

### 담당 업무 주요 내용

- 사용자 세션 유지를 위한 전역 변수 관리
- **정규 표현식**으로 입력값 검증 분기 처리(로그인, 회원가입 등)
- 아이디·비밀번호 찾기 등 예외 상황 대응 UI 구성
- 출발지와 도착지 선택을 위해 항공 스케줄을 테이블로 표시하는 UI 구현
- 탑승일 선택을 위한 달력 UI 개발 (마우스클릭·키보드로 날짜 입력 가능)
- 탑승 인원 수 선택 UI 구현 및 나이 계산기(성인·소아·유아 구분)
