## 프로젝트별 메모

### 임베디드·디지털 회로

- **KorchamLogis** (팀) — C 프로그래밍 수업 중 Arduino/Tinkercad로 진행한 첫 미니 프로젝트. Controller UNO와 Displayer UNO 역할을 분리한 Dual Arduino 구조로 주행·표시 시스템을 구현했습니다.
- **Timepiecer** (팀) — Verilog HDL 실습 직후 Basys 3에서 Timepiece와 Timer 기능을 통합한 프로젝트. Timepiece FSM·datapath 설계와 top 모듈 통합, 검증·발표 자료 정리를 담당했습니다.

### UART·FIFO·센서 인터페이스

- **UART·FIFO RTL** (개인) — UART TX/RX loopback과 FIFO 제어를 Verilog RTL과 testbench로 구현했습니다.
- **ascii-uart-sensor-pipeline** (팀) — UART·FIFO·ASCII codec에 SR04·DHT11 센서, watch·stopwatch 기능을 더해 하나의 Basys 3 시스템으로 통합했습니다.

### SystemVerilog 검증·UVM

- **SystemVerilog UART·FIFO 검증** (개인) — `class`·`interface`·`mailbox`·`event`·`fork-join` 기반 class 테스트벤치로 UART TX/RX·FIFO·loopback 단위·통합 검증을 진행했습니다.
- **UVM SPI·I2C** (개인) — SPI·I2C controller/target RTL을 UVM environment(generator·driver·monitor·scoreboard)로 검증하고, Basys 3 보드 constraints와 build script까지 구성했습니다.

### CPU·SoC

- **RV32I CPU** (개인) — RV32I single-cycle datapath·control RTL을 설계하고 instruction type별 testbench와 program memory 예제로 검증했습니다.
- **AXI_Peripheral** (팀) — MicroBlaze SoC에 AXI4-Lite custom peripheral을 결합한 프로젝트. IIC custom IP와 register·HAL·firmware 경로 구현, board-to-board 검증을 담당했습니다.

### ARM Cortex-M4 firmware

- **Testudines** — NUCLEO-F411RE와 Sensor Shield v5.0으로 G51 6DoF 로봇팔을 구동하는 bare-metal firmware 프로젝트. Build·startup 구조 정리, `TIM4_CH1` 첫 서보 PWM bring-up, 6채널 servo PWM, UART pulse-echo 상태 출력, joystick ADC 입력까지 구현하고 시연을 완료했습니다.

### On-Device AI

- **Wardy** (3인 팀 '지켜조') — Jetson Orin Nano 기반 가정용 돌봄 안전 모니터링 시스템. USB 웹캠 영상에서 사람 탐지(YOLO11n) → 익명 추적(Kalman Filter·Hungarian assignment) → 자세 추정(RTMPose) → 낙상 의심 판단(TemporalFallGRU)으로 이어지는 파이프라인에 위험물 근접 탐지와 로컬 LLM(Ollama) 기반 일일 요약을 더해 C++ edge runtime과 browser UI로 통합했습니다.
