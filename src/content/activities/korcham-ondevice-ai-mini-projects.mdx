## 프로젝트별 메모

<DateSortItem date="2026-09-09">

### LightLetter (Final Project)

<VideoTag filename="lightletter-tx-ui.mp4" title="LightLetter 송신 UI" />

- 7인 팀 'LLINK', CNN Output Buffer·FC 설계 담당
- 손글씨 문자를 FPGA CNN으로 인식하고 BFSK 광통신으로 전송해, 수신 보드에서 FFT로 복원하는 Zybo Z7-20 2대 시스템
- CNN Convolution 후단 Output Buffer와 ReLU·양자화 블록을 설계하고 Python = C = RTL bit-exact까지 확인
- 팀이 공유하는 Fully Connected 연산기(병렬도 P = 20)를 설계하고 파이프라인 단계를 추가해 타이밍 확보
- TX 보드 Vivado 경고와 타이밍 위반을 분석하고 수정 전후 검증 결과를 기록

</DateSortItem>

<DateSortItem date="2026-08-31">

### VGA Pan-Tilt CCTV

<VideoTag filename="vga-pan-tilt-cctv-demo.mp4" title="VGA Pan-Tilt CCTV 시연" />

- 7인 팀 '도리도리', 모터 파트 `servo_top` 단독 담당
- Basys 3와 OV7670으로 색·엣지·움직임 기반 대상을 검출하고 Pan·Tilt 2축 서보로 대상을 화면 중앙에 유지하는 능동형 CCTV
- `servo_top`의 인터페이스 명세, 모듈 설계서, 검증 계획 작성
- 영상 파트의 좌표 오차를 Pan·Tilt 각도 변화로 바꾸는 축 제어, 제어 모드 mux, `servo_pwm` 2채널 설계
- 단위 self-check testbench와 `servo_top` UVM 환경으로 검증 계획 구성

</DateSortItem>

<DateSortItem date="2026-08-05">

### Wardy (On-Device AI)

<DriveAssetGrid actId="korcham-mini-wardy" layout={[28, 72]} />

- 3인 팀 '지켜조', M-02 익명 추적·M-03 자세 추정·M-04 낙상 감지 담당
- Jetson Orin Nano에서 USB 웹캠만으로 낙상 의심·장시간 정지·위험물 근접을 감지하고 사건·증거 자료로 정리하는 가정용 돌봄 안전 모니터링 시스템
- M-02: Kalman Filter·IoU Gate·Hungarian assignment로 사람마다 익명 `track_id` 부여
- M-03: RTMPose-M으로 COCO-17 keypoint를 추정하고 자세 분류
- M-04: 20 frame(2초) 관절 시퀀스를 받는 TemporalFallGRU와 standing→lying 급전환 Fast Path로 낙상 판단

</DateSortItem>

### Testudines (ARM Cortex-M4 firmware)

<VideoTag filename="testudines-full-joint-run-x2.mp4" title="Testudines 전체 관절 구동" />

- NUCLEO-F411RE와 Sensor Shield v5.0으로 G51 6DoF 로봇팔을 구동하는 bare-metal firmware 프로젝트

- 6채널 servo PWM과 joystick ADC 입력으로 로봇팔 관절 제어
- UART pulse-echo 상태 출력을 더해 시연까지 완료

</DateSortItem>

### UVM SPI·I2C

<DriveAssetGrid actId="korcham-mini-uvm-spi-i2c" layout={[50, 50]} />

- 개인 프로젝트
- SPI·I2C controller/target RTL을 직접 구현하고 UVM 1.2 testbench로 자동 검증
- SPI는 MODE0 1-byte MSB-first full-duplex, I2C는 7-bit address `0x12` 1-byte write와 ACK 검증
- smoke·basic·boundary·random·back-to-back·regression sequence와 scoreboard·functional coverage·collector report로 검증 근거 정리
- Basys 3 보드 constraints와 build script까지 구성

</DateSortItem>

### RV32I CPU

<DriveAssetGrid actId="korcham-mini-rv32i" layout={[40, 60]} />

- 개인 프로젝트

- instruction/data memory, control, datapath, program counter, register file, ALU를 나눠 구현하고 R/I/S/B/U/J 형식 지원
