### LightLetter (Final Project)

<VideoTag filename="lightletter-tx-ui-x2.mp4" title="LightLetter 송신 UI (2배속)" />

- 7인 팀 'LLINK', Zybo Z7-20 두 대로 손글씨를 FPGA CNN으로 인식해 BFSK 광통신으로 보내고 수신부 FFT로 복원
- **설계 대상:** CNN Convolution 출력단(Output Buffer, ReLU & Quantization, 채널 재정렬)과 공유 Fully Connected 연산기(P = 20), 송신 보드 ArUco 크롭 C
- **목적:** Convolution 결과를 다음 단 순서·비트 폭으로 손실 없이 넘기고, FC를 DSP 40개에서 20개로 줄이기
- **검증 방식:** Python QAT · C 골든 모델 · RTL bit-exact 비교, Vivado OOC 합성·SAIF 전력, Zybo 보드 70장 실측
- 상세: [LightLetter](lightletter.mdx)

</DateSortItem>

<DateSortItem date="2026-08-31">

### VGA Pan-Tilt CCTV

<VideoTag filename="vga-pan-tilt-cctv-demo-x2.mp4" title="VGA Pan-Tilt CCTV 시연 (2배속)" />

- 7인 팀 '도리도리', Basys 3와 OV7670으로 녹색 객체를 검출하고 Pan·Tilt 서보로 화면 중앙에 유지하는 CCTV
- **설계 대상:** 서보 제어부 `servo_top`(`ctrl_mode_mux`, `servo_pwm` 2채널, `axis_ctrl` 통합)과 보드 시험용 `servo_pwm_check_sw`
- **목적:** 영상 추적 오차와 조이스틱 변화량을 하나의 각도 제어 경로로 받아 SG90 두 개를 50 Hz PWM으로 구동
- **검증 방식:** 펄스 폭·주기 self-check testbench, 조이스틱 RTL 연결 testbench, 서보 입력 직전까지 영상 경로의 Python 골든 모델 6단계 bit-exact 비교
- 상세: [VGA Pan-Tilt CCTV](vga-pan-tilt-cctv.mdx)

</DateSortItem>

### Wardy (On-Device AI)

<DriveAssetGrid actId="korcham-mini-wardy" layout={[28, 72]} />

- 3인 팀 '지켜조', Jetson Orin Nano와 USB 웹캠으로 낙상 의심·장시간 정지·위험물 근접을 감지하는 가정용 돌봄 모니터링
- **설계 대상:** M-02 익명 추적, M-03 자세 추정, M-04 낙상 감지 모듈과 Python 추론 Runtime, C++ Edge Service 연동, 브라우저 UI
- **목적:** 사람마다 끊기지 않는 track 위에서 자세 변화를 시간축으로 봐 일상적인 눕기와 실제 낙상을 구분
- **검증 방식:** 추적기 후보 IDF1·MOTA·ID switch·지연시간 비교, 08-13\~08-18 실물 낙상·오탐 반복 시험, Edge·UI unit·integration 테스트
- 상세: [Wardy](wardy.mdx)

</DateSortItem>
