draw.io 저장한거 올려두기

| 상태 | 설명 |
|------|------|
| STANDBY | 대기 중인 상태. 작업 명령 또는 충전 요청을 기다림 |
| CHARGING | 지정된 충전소에서 충전 수행 중 |
| DRIVING | 픽업/스토어 위치로 이동 중 |
| PRECISION STOP | 지정 위치에 정밀 정지 시도 |
| PICKUP | 상품을 랙에서 집는 작업 수행 |
| DELIVERY | 픽업한 상품을 지정 스토어 위치로 운반 |
| WAIT | 도착 후 사용자 응답 대기 또는 확인 처리 시간 |
| RETURN | 모든 작업 완료 후 대기 위치로 복귀 |
