## Use Case 목록

| Use Case ID | 시나리오 명 | 설명 | 사용 기술 |
|------------|-------------|------|-----------|
| UC_01 | 자율 주행 기반의 창고 내 물류 이동 | 경로를 따라 이동하며 장애물과 사람을 회피, 비상 상황 대응 포함 | Raspberry Pi 5를 중심 제어기로 사용하여, IMU 센서로 자세를 보정하고, LiDAR 및 초음파 센서를 통해 장애물 정보를 수집하며, IR 센서와 카메라(YOLO)로 사람 및 로봇을 감지하여 회피 경로를 계산한다. DC 모터로 이동을 수행하고, 부저와 LCD를 통해 상태와 경고를 표시한다. |
| UC_02 | 물품 배송 요청에 따른 A → B 운송 | 지정된 출발지에서 도착지까지 자동 배송 수행 | LiDAR와 카메라로 실시간 경로 인식 및 위치 추정을 수행하고, IMU와 함께 이동 방향을 제어하며 DC 모터를 통해 자율 이동한다. Raspberry Pi는 전체 경로 탐색 알고리즘과 로직을 제어한다. |
| UC_03 | 복수 로봇 간 협업 기반 동시 물류 처리 | 작업량에 따라 역할 분담 및 충돌 방지, 협업 운송 | Raspberry Pi의 무선 통신 기능을 이용해 로봇 간 상태와 작업 정보를 공유하며, 카메라(YOLO)로 주변 물체 및 다른 로봇을 인식하여 충돌을 방지하고, 협업 알고리즘을 통해 작업 분담을 조정한다. |
| UC_04 | QR Mapping을 통한 위치 식별 및 보정 | QR 코드 기반 현재 위치 파악 및 정밀 정차 수행 | 카메라(OpenCV)를 통해 QR 코드를 실시간으로 인식하고, Raspberry Pi가 위치 보정 알고리즘을 적용해 정밀하게 위치를 보정 및 정차한다. |
| UC_05 | 로봇 물류 처리 중 재고 파악 및 로깅 | 로봇이 물건을 처리하면서 재고 상태 감지 및 기록 | 카메라(YOLO)를 통해 물체를 분류하고, Load Cell을 통해 실시간 무게 변화를 측정하여 재고 상태를 판단하며, Raspberry Pi가 이를 로깅하여 저장한다. |
| UC_06 | 사람이 인한 물건 제거 후 재고 감지 | 사람이 물건을 집었을 때 재고 변화 자동 감지 및 반영 | IR 센서로 근접 감지를 수행하고, Load Cell로 무게 변화를 감지하여 물건이 제거되었는지를 판단하며, 카메라(YOLO)는 변화 상황을 시각적으로 보조하여 Raspberry Pi에서 재고 변동을 처리한다. |
| UC_07 | 로봇 상태 모니터링 및 사용자 표시 | 배터리 상태 및 동작 상태를 UI·LED로 사용자에게 표시 | 배터리 잔량을 실시간으로 측정하고, LCD 및 LED 디스플레이를 통해 상태 정보를 사용자에게 시각적으로 제공하며, Raspberry Pi는 부저를 통해 경고음을 송출한다. |
| UC_08 | 로봇 배터리 부족 시 자동 충전 도킹 | 배터리 임계 도달 시 충전소로 자율 이동하여 충전 | 배터리 측정 회로로 잔량을 모니터링하고, Raspberry Pi가 QR 코드 인식을 통해 충전소 위치를 파악한 뒤, 도킹 알고리즘을 실행하여 충전소에 정밀하게 도킹한다. |
| UC_09 | 운영 중 장애 발생 시 자동 정지 및 보고 | 긴급 정지 및 자가 진단, 오류 상황 서버·사용자 전송 | LiDAR, 초음파, IR 센서를 통해 장애를 감지하고, Raspberry Pi가 DC 모터 동작을 차단하며 부저와 디스플레이를 통해 사용자에게 경고를 전달하고, 무선 통신으로 서버에 자동 보고한다. |
| UC_10 | 사용자 호출 후 인터페이스 제어 | 사용자가 로봇을 호출하고 명령을 입력할 수 있음 | 무선 통신 기능으로 사용자 요청을 수신하며, 버튼 입력 혹은 음성 인식을 통해 Raspberry Pi에서 명령을 처리하고 해당 동작을 수행한다. |
| UC_11 | 교대 근무 로봇 스케줄 자동화 | 교대 시간 또는 업무량에 따라 로봇 자동 전환 운영 | Raspberry Pi에 내장된 시간관리 로직을 통해 교대 시간을 판단하고, 스케줄링 알고리즘을 적용해 로봇 운용을 자동으로 전환한다. |
| UC_12 | 야간 순찰 및 실내 보안 기능 수행 | 정해진 순찰 순환 중 이상 감지 시 관리자 알림 전송 | LiDAR, 카메라, 초음파 센서를 통해 주변 상황을 지속 감시하고, Raspberry Pi가 알림 모듈과 연동되어 비정상 상황을 관리자에게 자동 보고한다. |

## 기능 리스트 (System Requirement)

| SR_ID | 기능 명 | 사용 하드웨어 | 소프트웨어 기술 | 비고 |
|------|---------|---------------|-----------------|------|
| SR_01 | 지정된 경로 또는 목적지로 자율 이동 | LiDAR (SLAMTEC RPLiDAR C1), IMU (ICM-20948), 모터 드라이버 | SLAM, Path Planning (Dijkstra, A*), ROS2 Navigation Stack | 지도 기반 경로 탐색 및 제어 |
| SR_02 | 실시간 장애물 감지 및 회피 경로 탐색 | 초음파 센서(HC-SR04), IR 센서(TCRT5000), LiDAR | Obstacle Avoidance, Costmap, Sensor Fusion | Depth 센싱 기반 회피 알고리즘 |
| SR_03 | 사람 인식 및 안전거리 유지 | Pi 카메라, LiDAR | OpenCV, CNN 기반 Object Detection, YOLO, 거리 계산 | 사람 위치 추정 및 충돌 방지 |
| SR_04 | 긴급 정지 | IR 센서, Buzzer, Motor Driver | 인터럽트 처리, 이벤트 감지 루틴 | 조건 만족 시 모터 중단 및 경고 |
| SR_05 | 재고 파악 기능 | Pi 카메라 | QR 코드 인식(OpenCV), OCR(Tesseract) | 물품 인식 및 위치 정보 파악 |
| SR_06 | 물건 배송 | 모터 시스템, IMU, LiDAR | Waypoint 기반 자율 주행, FSM | 목적지 기반 정밀 정차 포함 |
| SR_07 | 복수 로봇 간 충돌 방지 협업 | Wi-Fi, IMU, LiDAR | ROS2 Multirobot 통신, Topic 공유, TF | ID 기반 충돌 방지 |
| SR_08 | 사용자 요청에 따른 협업 운반 | Wi-Fi, 모터, 카메라 | Task Scheduling, Command Interface, GUI 연동 | 명령 기반 유연 대응 |
| SR_09 | QR Mapping 기반 위치 확인 | 카메라, QR Code | OpenCV, QR Mapping DB | 정밀 위치 보정 |
| SR_10 | 장애 자가 진단 및 오류 자동 보고 | 전체 센서 | ROS2 Diagnostics, 로그 분석 | 상태 리포트 자동 전송 |
| SR_11 | 배터리 잔량 감지 및 알림 | 배터리 전압 센서 | Voltage Monitoring Script, ROS2 상태 전송 | 임계치 이하 경고 |
| SR_12 | 자동 충전 도킹 기능 | IR 센서, 초음파 센서 | Line Tracking, Docking 알고리즘 | 충전소 정렬 후 도킹 |
| SR_13 | LED·디스플레이 상태 표시 | 2.4” LCD, LED | ST7789 드라이버, SPI, UI | 상태 시각화 |
| SR_14 | 작업 기록 저장 및 전송 | SD 카드, Wi-Fi | ROS2 Logging, CSV, MQTT·HTTP | 로컬·클라우드 선택 |
| SR_15 | 협업 스케줄링 | 내부 시계, Wi-Fi | ROS2 Task Scheduler, Timer | 로봇 간 동기화 |
| SR_16 | 지정 위치 정밀 정차 | LiDAR, IMU, 휠 인코더 | Pose Estimation, EKF, PID | ±5cm 이내 정차 |
