## GUI 구성 개요

본 시스템은 **Staff용 GUI**와 **Manager용 GUI**로 구성되며,  
각 사용자의 **권한 및 역할**에 따라 정보 표현 방식과 기능이 분리되어 있다.

- 두 GUI 모두 **PyQt 기반**으로 구현
- 각 기능은 **시스템 요구사항(SR)** 과 연계됨
- 보안 및 역할 분리를 위해 **독립 실행 프로그램**으로 동작

## MANAGER GUI (MANAGER PC)

### 기능 구성

#### 대시보드

| 세부 기능 설명 | 관련 SR |
|---|---|
| 실시간 Roscar 상태 요약 (위치, 상태, 배터리 등) | SR-601, SR-602 |
| 실시간 경로 및 장애물 회피 상태 시각화 | SR-104, SR-105, SR-401, SR-402 |
| 시스템 경고 알림 (충돌 위험, 회피 실패, 정체 등) | 시나리오 기반 기능 |
| 정체 경고: 일정 시간 이상 위치 변화 없음 감지 | 시나리오 기반 기능 |

---

#### Roscar 상태 모니터링

| 세부 기능 설명 | 관련 SR |
|---|---|
| 각 Roscar 상세 상태 조회 (Idle · 작업중 · 충전 등) | SR-601, SR-603 |
| 정밀 정차 실패, 픽업 실패 등 이벤트 상태 확인 | SR-106, 시나리오 기반 기능 |
| 배터리 수준 모니터링 | SR-203 |

---

#### 작업 요청 현황

| 세부 기능 설명 | 관련 SR |
|---|---|
| 전체 작업 요청 이력 조회 (상태, 시간, 결과 등) | SR-502, SR-503 |
| 요청 상세 정보 확인 (출발지 · 도착지 · 신발 정보 등) | SR-503, SR-605 |
| 요청 상태 기반 필터링 (대기중, 배송중, 완료 등) | SR-502, SR-506 |

---

#### 작업 이벤트 로그

| 세부 기능 설명 | 관련 SR |
|---|---|
| Roscar 이벤트 이력 조회 (작업 시작·종료, 충돌 등) | SR-603 |
| 작업 이벤트 이력 조회 (요청 생성, 픽업 완료 등) | SR-604 |
| 이벤트 필터 및 시간 범위 조회 | SR-608, SR-609, SR-610 |

---

#### 작업 자동 배정

| 세부 기능 설명 | 관련 SR |
|---|---|
| Idle 상태 & 배터리 ≥ 20% 조건 만족 시 자동 배정 | 시나리오 기반 기능 |
| 대기 큐 등록 및 우선순위 점수 계산 | 시나리오 기반 기능 |
| 최대 대기시간 초과 시 경고 알림 | 시나리오 기반 기능 |
