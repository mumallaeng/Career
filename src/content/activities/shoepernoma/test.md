## 정리 전제 및 작성 규칙

* **TC_ID / 마지막 진행일 / 결과코드**는 엑셀 함수로 관리되므로 하드코딩하지 않음
* **매칭 UR/SR**은 향후 변경 가능성이 있으므로 고정 값으로 미리 작성하지 않음
* **셀 병합 금지** (정렬 문제 방지)
* **이슈 또는 설명**

  * 짧은 내용: 엑셀 셀에 직접 작성
  * 긴 설명: Confluence 페이지 생성 후 링크로 관리
* **Confluence Header 사용 시**

  * Header 단위로 URL이 생성되므로 **같은 페이지 내에서는 항목별로 셀을 분리하여 관리**
* 엑셀 링크
  [https://redacted.invalid/sharepoint-link-removed) your OneDrive account

## 테스트 케이스 분류 체계

### Roscar 주행 및 정밀 정차

* 대기 장소로 이동 테스트
* 호출받은 목적지로 이동 테스트
* 지정된 렉으로 이동 테스트
* 지정 위치 정밀 정차 테스트

### 장애물 및 객체 인식

* 객체 탐지 후 정지 테스트
* 객체 탐지 후 회피 테스트
* 사람 탐지 테스트
* 장애물 탐지 테스트
* 협업 로봇 탐지 테스트

### 작업 수행

* 수레 내 제품 확인 테스트

### 경로 계획 및 회피

* 전역 경로 계획 테스트
* 장애물 회피 경로 수정 테스트

### 작업 관리 및 요청 처리

* 작업 전송 테스트
* 작업 요청 목록 확인 테스트
* 작업 취소 요청 테스트

### 재고 파악 및 조회

* QR 인식 재고 파악 테스트
* Manager 재고 확인 테스트

### 로봇 상태 / 작업 이벤트 로그

* 로봇 동작 상태 표시 테스트
* 작업 상태 구분 테스트
* 작업 요청 기록 저장 및 조회 테스트
* 로그 확인 테스트
* 로봇 이벤트 기록 확인 테스트
* 작업 이벤트 기록 확인 테스트
