## 확인 목적

로봇이 재고를 실시간으로 QR 코드 기반으로 인식하고, 인식된 제품 정보를 시스템에 등록하여 관리자가 정확하게 조회·검색·검증할 수 있도록 재고 인식 → 등록 → 조회의 전 과정을 정의하고 검증한다.

---

## 주요 조사 항목

| 항목명              | 조사 내용                                                                                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| QR 인식 대상 및 부착 위치 | 제품 상자 전면 또는 상단에 QR 코드 부착<br>QR 정보: 제품 ID, 색상, 사이즈 등 포함 (예: N123-RED-245)<br>랙별 위치 데이터와 결합하여 실제 보관 위치 추정 가능                                                         |
| QR 코드 인식 방식      | 로봇 탑재 카메라 + OpenCV 기반 QR 디코더 사용<br>인식 결과를 ROS 토픽 /qr_scan_result로 퍼블리시<br>예시 메시지:<br>{ "class": "qr", "data": "N123-RED-245", "position": { "x": 1.2, "y": 0.5 } } |
| 재고 파악 처리 로직      | 인식된 제품 데이터를 수레 또는 랙 ID와 함께 DB에 저장<br>동일 제품 중복 인식 시 수량 누적 처리<br>인식 실패 또는 오인식 발생 시 “재고 파악 실패” 상태 기록<br>파악 결과를 /inventory_status 등으로 전송 가능                            |
| 관리자 조회 기능        | Manager GUI에서 실시간 재고 확인 가능<br>필터 옵션: 제품명, 색상, 사이즈, 위치, 수량 등<br>조회 결과는 DB 직접 조회로 최신 상태 반영<br>검색 후 상세 보기, 위치 강조 표시 등 확장 기능 가능                                        |
| 시스템 연동 구조        | QR 인식 → 로봇이 DB 또는 서버에 inventory_log 등록<br>등록된 재고는 관리 시스템에서 즉시 조회 가능<br>관리자 수동 재고 보정 기능(등록·삭제) 병행 제공 가능                                                             |
| 테스트 시나리오         | QR 부착 제품 3종 배치 후 로봇의 순차 인식 여부 확인<br>DB 및 관리자 페이지에서 재고 수 자동 반영 확인<br>QR 오인식·미인식 시 상태 로그 및 경고 메시지 확인<br>관리자 필터 검색 테스트(예: “245 사이즈만 보기”)                              |
