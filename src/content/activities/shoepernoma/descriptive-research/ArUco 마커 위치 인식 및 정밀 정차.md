## 확인 목적

로봇이 지정된 위치에 도달했을 때 목표 좌표와의 **위치 오차(예: ±5cm)**가 허용 범위 내에 있는지를 자동으로 판별한다.
이를 위해 **자체 위치 추정(AMCL)**과 함께 ArUco 마커를 활용한 **외부 위치 인식 기반 정밀 보정 기능**을 추가하여 정밀 정차 판단의 신뢰도와 정확도를 개선한다.

---

## 주요 조사 항목

| 항목명               | 조사 내용                                                                                                                                        |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 정밀 정차 기준          | 위치 오차: 거리 기준 ±5cm 이내<br>방향 오차(선택): 회전 각도 ±5도 이하<br>기준 좌표: goal_pose vs /amcl_pose 또는 마커 기준 좌표                                                |
| 오차 계산 공식          | distance_error = sqrt((goal.x - current.x)^2 + (goal.y - current.y)^2)<br>orientation_error = abs(goal.theta - current.theta)                |
| 정차 판단 방식          | 목표 도달 직후 2~3초간 velocity ≒ 0 상태 유지 여부 확인<br>단순 도달이 아닌 안정적 정지 상태 포함하여 판정                                                                       |
| 위치 확인 방식          | /amcl_pose: 내부 위치 추정 기반 (드리프트 발생 가능)<br>ArUco 마커 인식: 외부 기준 정밀 보정 방식<br>/roscar/object_detections 토픽 활용<br>인식된 마커 ID 및 위치 기반으로 로컬 pose 수정     |
| ArUco 마커 기반 보정 방식 | 벽면에 마커 부착 후 map 프레임 기준 고정 좌표로 등록<br>마커 인식 성공 시 로봇 pose를 해당 마커 좌표로 보정<br>예: /roscar/pose/update를 통해 현재 위치 재등록<br>마커 ID → 고정 좌표 변환 테이블(Map) 사용 |
| 성공 판별 조건 예시       | distance_error < 0.05 이고 velocity < 0.01 인 경우 정밀 정차 성공으로 판정                                                                                  |
| 테스트 시나리오          | ArUco 마커 인식 → 위치 보정 성공 → ±5cm 오차 이내 도달 여부 확인<br>마커 인식 실패 시 /amcl_pose 기준으로 판단하는 fallback 동작 확인<br>마커 인식 정확도, 거리, 각도에 따른 정지 성공률 측정            |
| 적용 시 고려사항         | 마커는 벽면 기준 약 1m 이내 거리에서 고정 설치 필요<br>카메라 시야 확보 및 조명 조건 유지 필수<br>마커 인식 실패 대비 fallback 경로 마련 필요 (예: IMU 기반 지속 추정)                                |
