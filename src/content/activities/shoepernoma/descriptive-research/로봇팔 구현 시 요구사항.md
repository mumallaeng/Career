## 확인 목적

로봇팔을 대상으로 강화학습 기반 제어 시스템을 구성하기 위해 필요한 하드웨어 요소, 소프트웨어 구성, 학습 설계 기준을 정리하고, 시뮬레이션에서 학습된 모델을 실환경에 적용할 수 있도록 전체 구조를 정의한다.

---

## 주요 조사 항목

| 항목명           | 내용                                                                                                                                                      |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 하드웨어 구성 요소    | 제어 가능한 로봇팔 (6DoF 이상, ROS2 드라이버 제공)<br>제어용 PC 또는 SBC (예: Jetson, 라즈베리파이5)<br>장애물 감지를 위한 센서 (LiDAR 또는 Depth Camera)<br>선택 센서: Force Sensor, Joint Encoder |
| 시뮬레이션 환경      | ROS2 + Gazebo 사용<br>로봇팔 모델 및 장애물 환경 구성<br>반복 학습을 위한 자동화 시뮬레이션 설정                                                                                        |
| 학습 프레임워크 구성   | Stable-Baselines3 사용 (PPO, DQN 등)<br>OpenAI Gym 형식의 Custom 환경 제작<br>ROS ↔ Gym 연동을 위한 ros_gym_bridge 또는 gym_gazebo2 사용                                   |
| 학습 설계 요소      | 상태(State): 관절 각도, 목표 위치까지 거리, 장애물 거리<br>행동(Action): 관절별 각도 증분 또는 IK 기반 위치 제어<br>보상(Reward):<br>목표 도달 시 +100<br>충돌 시 -100<br>진동/비효율 -1                   |
| 모델 적용 구조      | 학습된 모델을 .pt 또는 .onnx 형식으로 저장<br>실로봇에 추론 전용 ROS2 노드로 적용                                                                                                  |
| 고급 설계 요소 (선택) | Safety Layer: 실로봇 충돌 방지<br>Domain Randomization: 시뮬↔실물 전이 성능 향상<br>Curriculum Learning: 난이도 점진 증가<br>Fine-tuning: 실로봇 환경에서 재학습                          |
