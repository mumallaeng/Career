## 확인 목적

장애물의 종류에 따라 로봇의 대응 방식이 달라지므로, 탐지 모델이 사람, 협업 로봇, 일반 물체를 정확히 구분할 수 있는지 여부를 사전에 점검해야 한다.
이를 통해 회피, 정지, 협업 등 후속 제어 로직이 의도대로 실행되도록 보장한다.

---

## 주요 조사 항목

| 항목명             | 조사 내용                                                                                                                                                                         |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 탐지 모델 구성        | 커스텀 객체 탐지 모델 사용 (예: YOLOv5)<br>학습 클래스: person, roscar(협업 로봇), box 등<br>각 객체는 고유한 Class ID로 분류되어 동작 제어 로직에 활용                                                                  |
| 라벨링 기반 협업 로봇 탐지 | 협업 로봇은 자체 이미지 수집 후 라벨링 및 학습 수행<br>테스트 환경에서 높은 신뢰도로 탐지 가능<br>ArUco 마커 없이 영상 기반 탐지만으로 동작 분기 가능                                                                                  |
| 탐지 후 행동 분기      | 탐지된 클래스에 따라 행동 분기 수행 가능<br>person → 즉시 정지<br>roscar → 감속 또는 정지                                                                                                                |
| 테스트 방법          | 다양한 객체(사람, 협업 로봇, 박스 등) 배치 후 탐지 결과 확인<br>/object_detections 토픽 또는 내부 명령으로 탐지 결과 검증<br>예시 출력:<br>{ "class": "roscar", "confidence": 0.91, "position": { "x": 1.2, "y": 0.5 } } |
| 모델 성능 요약 (예시)   | 사람 탐지 정확도(mAP): 92%<br>협업 로봇 탐지 정확도: 88%                                                                                                                                      |
