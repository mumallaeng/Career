## 확인 목적

장애물을 인식한 후 로봇이 **회피할지 정지할지 판단하는 기준**이 명확히 정의되어야 시나리오 기반 테스트가 의도대로 작동하는지 검증할 수 있다.
로직 분기 조건, 판단 위치, 테스트 시나리오를 사전에 정리함으로써 예외적 동작이나 불확실한 반응을 사전에 방지한다.

---

## 주요 조사 항목

| 항목명           | 조사 내용                                                                                                                                                                                   |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 회피/정지 판단 조건   | 거리 기준:<br>장애물까지 거리 ≤ 0.6m → 회피 시도<br>거리 ≤ 0.3m + 유효 경로 없음 → 정지 전환<br><br>각도 기준:<br>정면 ±45도 범위(총 90도) 이내 감지 시 회피/정지 판단 대상으로 간주                                                           |
| 판단 로직 위치      | Behavior Tree 조건 노드 (CheckObstacleCondition, IsBlocked 등)<br>Local Planner 내 경로 상태 코드(planner_status)<br>Velocity Controller에서 직접 정지 조건 분기                                              |
| 로직 분기 시 로그 예시 | 장애물 감지:<br>[planner]: Obstacle detected within threshold (0.4m)<br><br>회피 시도:<br>[behavior]: Attempting avoidance maneuver...<br><br>정지 판정:<br>[controller]: Path blocked, robot halted |
| 테스트 시나리오      | 장애물 위치 다양화: 정면, 측면, 후방<br>거리 변화에 따른 회피 vs 정지 판단 확인<br>/roscar/obstacle/response 및 /roscar/avoidance/cmd 메시지 내용 확인<br>로그 메시지 기준으로 로직 분기 검증 수행                                            |
