## 확인 목적


### 확인 목적

로봇의 이동 정확도에 영향을 미치는 주요 요소인 **맵 해상도**, **목표 좌표 설정 방식**,  
**경로 계획 환경 구성**을 사전에 정의하고,  
테스트 과정에서 발생할 수 있는 **위치 오차** 또는 **목적지 도달 실패**의  
근본 원인을 사전에 차단하기 위한 **구조적 기준**을 마련한다.


---

## 주요 조사 항목


### 주요 조사 항목

| 항목명 | 조사 내용 |
|------|----------|
| 맵 해상도 | `.yaml` 파일 내 `resolution` 필드에서 정의됨<br>예: `resolution: 0.05` → 1픽셀당 5cm<br><br>해상도가 높을수록 경로 정확도는 증가하나 연산량 증가<br>**테스트 기준:** `0.05` 이하 권장 |
| 맵 생성 방식 | **SLAM 자동 생성** (Cartographer, SLAM Toolbox 등)<br>→ 실시간 맵 갱신 가능하나 노이즈 및 드리프트 존재<br><br>**수동 생성** (Photoshop, Inkscape 등)<br>→ `.pgm` + `.yaml` 직접 제작, 정확한 스케일 설정 필요 |
| 목적지 좌표 설정 방식 | RViz에서 **2D Nav Goal** 클릭 → `/roscar/navigation/goal` 토픽 전송<br>또는 YAML / DB에 사전 정의된 목표 좌표 사용<br><br>※ 항상 `map` 프레임 기준 `Pose(x, y, θ)` 사용 필수 |
| 좌표 정확도 영향 요소 | SLAM 기반 맵 사용 시 드리프트 발생 가능 → `/initial_pose` 설정 정확도 중요<br><br>Costmap의 `inflation_radius` 값이 클 경우 목표 지점 근접 불가 문제 발생 |
| Footprint 확인 | `robot_radius` 또는 `footprint` 파라미터가 실제 로봇 크기와 불일치 시<br>→ 충돌 회피 실패 또는 경로 이탈 가능성 발생<br><br>좁은 공간 주행 및 `/roscar/precision_stop/cmd` 기반 정밀 정차 시 영향 큼<br>RViz에서 실시간 시각 확인 가능 |


---


### 요약

- 맵 해상도는 **0.05m 이하**를 기준으로 설정
- SLAM 맵 사용 시 **초기 위치 설정 정확도**가 핵심
- 모든 목표 좌표는 **map 프레임 기준 Pose(x, y, θ)** 사용
- Costmap 파라미터(`inflation_radius`, `footprint`)는 **실제 로봇 크기와 일치** 필요
- RViz를 통한 **실시간 시각 검증** 필수
