## 확인 목적

로봇이 목표 지점에 도달했을 때, 위치 오차 및 방향 오차가 사전에 정의된 범위(예: ±5cm, ±5도) 내에 있는지를 자동으로 판단하기 위한 기준을 정립한다.
ROS2 Action 결과를 통해 정밀 정지 성공 여부를 정확히 판별할 수 있도록 메시지 설계 및 판정 알고리즘 기준을 명확히 한다.

---

## 주요 조사 항목

| 항목명         | 조사 내용                                                                                                                                                            |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 정밀 정차 기준    | 위치 오차: ±5cm 이하<br>방향 오차(선택): ±5도 이하<br>비교 기준: goal_pose vs /amcl_pose 또는 base_link                                                                               |
| 오차 계산 공식    | distance_error = sqrt((goal.x - current.x)^2 + (goal.y - current.y)^2)<br>orientation_error = abs(goal.theta - current.theta)<br>기준: distance_error < 0.05 (5cm) |
| 정차 판별 방식    | 목표 도달 직후 2~3초간 속도 ≒ 0 상태 유지 시에만 성공 판정<br>ROS 메시지 /robot/precision_stop/result 내 success: bool 필드로 보고                                                             |
| 정차 위치 확인 방식 | /amcl_pose 기준: 내부 위치 추정 기반 → 구현 간단, 드리프트 발생 가능성<br>QR · ArUco 기준: 마커 인식 기반 외부 정밀 측위 → 인식 실패 대비 필요                                                                |
| 성공 조건 예시    | if distance_error < 0.05 and velocity < 0.01:<br>  정밀 정차 성공                                                                                                      |
| 실제 적용 고려사항  | 바닥 재질, 슬립 등 환경 요인 고려 → 영역 내 도달 허용<br>장기 운용 시 QR 등 외부 기준과의 보정 로직 병행 추천                                                                                            |
