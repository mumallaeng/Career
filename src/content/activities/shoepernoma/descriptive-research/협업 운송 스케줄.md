## 확인 목적

복수 대의 로봇이 동시에 운영되는 환경에서 작업을 효율적으로 분배하고, 충돌 없이 협업 운송을 수행하기 위해 스케줄링 알고리즘, 우선순위 정책, 작업 충돌 방지 체계를 정의하고 그 동작 조건을 명확히 한다.
이를 통해 로봇 간 간섭을 최소화하고 자율 협력 운용의 기반을 확보한다.

---

## 주요 조사 항목

| 항목명              | 조사 내용                                                                                                                       |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 작업 요청 방식         | 외부 시스템(GUI/DB) 또는 운영자 수동 생성<br>ROS 기반 요청 수신: /roscar/task/request<br>필드 예시: 작업 ID, 출발지, 목적지, 우선순위, 기한 등                     |
| 스케줄링 알고리즘        | 할당 기준:<br>① 현재 로봇 위치<br>② 로봇 상태 (/roscar/status/log)<br>③ 잔여 작업 수<br>기본 방식: Greedy Matching<br>향후 ML 기반 동적 스케줄링 확장 고려       |
| 협업 방지 및 충돌 회피 정책 | 동일 구간 또는 동일 목적지에 대한 동시 접근 방지<br>예약 기반 작업 큐 또는 동선 예측 기반 충돌 회피 적용<br>예: 시간창(Time Window) 기반 충돌 가능성 탐지                         |
| 우선순위 정책 및 처리 로직  | 작업 요청에 Priority 필드 포함 (High / Medium / Low)<br>선점 가능(Preemption):<br>긴급 요청 발생 시 기존 작업 보류 가능<br>→ /roscar/task/preempt 구조 고려 |
| 시스템 연동 및 상태 모니터링 | 각 로봇 상태를 /roscar/status/log, /roscar/task/status로 실시간 수집<br>작업 완료 시 /roscar/task/complete로 자동 보고<br>상태 기반 작업 할당 로직과 연계 필요   |
| 테스트 시나리오         | 동일 시간에 작업 2건 생성 후 로봇 간 분배 여부 확인<br>우선순위가 다른 요청에 대한 선점 또는 지연 처리 확인<br>Busy 상태 로봇에 추가 작업이 할당되지 않는지 검증                         |
