title: Roscar 자율주행 물류 로봇 시스템 요구사항
---


## 적용 대상
신발 매장 내부 창고

## 취급 물품
다양한 신발 상자 (박스 단위 물류)

## 운영 조건
- 사람과 다수의 **Roscar(자율주행 물류 로봇)**가 협업
- 각 Roscar에는 **물건을 집어 올릴 수 있는 장치(로봇팔)**가 탑재되어 있음
- Roscar는 직원 요청 또는 스스로 판단하여 개별 또는 협력 방식으로 작업 수행
- 모든 Roscar는 역할 구분 없이 모든 기능을 수행 가능

| UR_17 | Roscar가 수행한 작업은 기록으로 남아야 하며, 필요 시 관리자 또는 직원이 조회할 수 있어야 한다 | O |
| UR_18 | 매장 직원은 Roscar를 직접 호출하여 필요한 작업을 요청할 수 있어야 한다 | O |
| UR_19 | Roscar의 현재 상태(위치, 배터리, 작업 상태 등)는 실시간으로 확인할 수 있어야 한다 | O |

|-------|----------|----------|

| UR_21 | 로봇팔은 물건을 안정적으로 들어올려 Roscar에 실을 수 있어야 한다 | R |

| UR_26 | 물건을 놓을 위치가 유동적인 경우에도 정확한 위치에 놓을 수 있어야 한다 | O |
| UR_27 | 필요 시 다른 Roscar와 물건을 주고받을 수 있어야 한다 | O |

## Roscar 간 협업 및 통신 관련 요구사항

| UR_ID | 기능 설명 | Priority |

| UR_30 | 모든 Roscar는 상태 정보를 실시간으로 공유하여 서로 간 충돌 없이 협력할 수 있어야 한다 | R |
