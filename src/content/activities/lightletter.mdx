> *[컨소시엄] 온디바이스AI 시스템반도체 설계 2기* 교육과정의 파이널 프로젝트입니다. \
> 과정 소개: [경기도 팹리스 아카데미 · 온디바이스AI 시스템반도체 설계 2기](korcham-ondevice-ai-semiconductor.mdx) \
> 다른 과정 프로젝트: [미니 프로젝트 모음](korcham-ondevice-ai-mini-projects.mdx)

화이트보드에 쓴 손글씨를 카메라로 촬영해 FPGA CNN 가속기로 인식하고, 인식한 문자를 레이저 빛에 실어 BFSK로 보낸 뒤 수신 보드에서 FFT로 주파수를 판별해 문자를 복원하는 시스템입니다. 손글씨 인식(CNN), 광통신(BFSK), 신호처리(FFT)를 Zybo Z7-20 두 대 위에서 하나의 송수신 흐름으로 묶었습니다.

## 프로젝트 정보

| 항목 | 내용 |

## 팀 구성

| 파트 | 팀원 | 담당 |
|:--|:--|:--|

| 광통신 | 박종웅 | BFSK 송신부, 광 송수신 회로, 보드 간 통신 검증 |
| 광통신 | 변호연 | BFSK 수신부, CRC 검증, FFT-RX Top 통합, UART 펌웨어 |
| FFT | 권재원 | Ping-Pong Buffer, FFT Core 데이터 흐름·제어, 128-point FFT Top |
| FFT | 박경민 | FFT Butterfly, Twiddle Factor, Power 연산, Ping-Pong Buffer UVM 검증 |

## 시스템 구조

| 구분 | 흐름 |
|:--|:--|
| 송신부 | Pcam 5C → ArUco 마커 기반 112×112 ROI(PS) → 전처리 28×28 → CNN 가속기(PL) → 패킷·CRC-8 → BFSK 변조 → 레이저 송신 |
| 수신부 | 광센서 BPW34 → XADC 961.538 kS/s → 128-point FFT·Power → BFSK 복조·CRC 검증 → UART → PC UI |

| 항목 | 내용 |
|:--|:--|
| CNN | Conv(3×3) 6채널 → Max Pool → Conv(3×3) 16채널 → Max Pool → FC 400→120→84→26 |
| 학습 | EMNIST 대문자 26 클래스, QAT, 정확도 94.13% |
| BFSK 주파수 | bit 0 60.096 kHz, bit 1 97.656 kHz, SYNC 120.192 kHz |
| 패킷 | Preamble(SYNC 4심볼) + SFD 0xD5 + Frame ID + Data + CRC-8(다항식 0x07) |
| FFT | 128-point Radix-2 DIT, 단일 Butterfly 재사용, 판별 Bin 8·13·16 |

CNN 가속기는 팀이 RTL로 직접 구현했고, Python·C 골든 모델과 RTL 출력을 비교하며 검증했습니다.

## 담당 작업

- Convolution 출력을 재정렬하는 Output Buffer와 ReLU & Quantization 블록을 설계했습니다.
- FC(Fully Connected) 연산기를 설계하고 최적화했습니다.
- 송신부 PS에서 ArUco 마커를 검출해 글자 영역을 잘라내는 C 코드와 사용자 UI를 구현했습니다.

## 결과

| 항목 | 결과 |
|:--|:--|
| 최종 시연 | 'HELLO' 다섯 글자를 촬영·인식·광 송신하고 수신부 UI에서 같은 문자열 복원 |
| CNN 가속기 | CPU 대비 6.22배 빠름(2582.13 µs → 415.15 µs), 전력 57.7%·에너지 93.2% 감소 |
| Zero Gating·Skipping | 연산 시간 12.3%, 에너지 16.6% 추가 감소 |
| FFT | Pipeline 구조로 7.49 µs, CPU 대비 7.08배, 100 MHz 타이밍 만족, 자원 1~3% 사용 |
| UVM 검증 | BFSK TX·RX와 FFT Buffer Coverage 100%(randomized 구간 99.41%) |

소문자를 포함한 문자 집합 확장, 오류 정정(FEC)과 재전송, 여러 문자의 연속 전송은 향후 개선 항목으로 남겼습니다.
