경기도 기능경기대회 사이버보안 직종에서 금메달을 수상했습니다.

<!--more-->

## 수상 개요
- **수상일**: 2019년 4월 8일
- **주최기관**: 경기도기능경기위원회  
- **상훈**: 금메달 (1위)
- **직종**: 사이버보안
- **경기 기간**: 2일

## 경기 내용
사이버보안 전 영역에 걸친 종합적인 실무 능력을 평가하는 경기였습니다.
Windows Server, Linux 환경에서의 보안 설정부터 네트워크 보안, 
침해 대응까지 실제 업무 환경과 동일한 조건에서 진행되었습니다.

## 주요 과제
### 시스템 보안 구축
- **Windows Server 2019, Windows 10, CentOS 7** 기반 가상화 환경 구성
- **AD 도메인, DNS, DHCP, FTP, SSH, Web** 등 다양한 서버 서비스 설치 및 구성
- 초기 보안 설정 및 강화 작업

### 네트워크 보안 설계
- **VLAN 기반 네트워크** 설계 및 트렁크, NAT, UTM 정책 설정
- 내-외부망 분리를 통한 보안 아키텍처 구현
- 스위치 콘솔/SSH 접근을 위한 **AAA 인증 체계** 구현 및 Radius 서버 연동

### 보안 정책 적용
- **SSH 포트 변경** 및 key 기반 접근 설정
- **root 직접 로그인 차단** 등 Linux 보안 정책 적용
- 웹 서버 **BasicAuth 적용** 및 FTP 홈 디렉토리 권한 설정
- 사용자 로그 추적(cmd.log, sulog), 계정 정책 설정

### 침해 분석
- **Kali Linux 기반 공격 서버** 구축
- **nmap 기반 IP 탐색** 및 취약점 분석 실습
- 침해 분석 보고서 작성

## 수상 의미
고등학생 시절 정보보안 분야에서 도달할 수 있는 최고 수준의 실력을 
공식적으로 인정받은 의미 있는 성과입니다. 
이는 이후 개발자로서의 기반이 되는 중요한 경험이었습니다.

## 얻은 역량
- 정보보안 전반에 대한 실무 수준의 이해
- 시스템 및 네트워크 보안 구축 능력
- 문제 해결 중심의 기술적 사고력
- 압박감 있는 상황에서의 집중력과 실행력
