[mumallaeng/StoneSpring](https://github.com/mumallaeng/StoneSpring) \
[addinedu-ros-8th/deeplearning-repo-3](https://github.com/addinedu-ros-8th/deeplearning-repo-3)


> *(KDT) ROS2와 인공지능을 활용한 자율주행 로봇 개발자 양성과정 8기* 교육과정 내에서 *Artificial Intelligence*을 주제로한 과제입니다.


사용자의 외로움을 덜어주고, 일상생활에서 필요한 정보를 비서처럼 알려주며, 정신 건강을 챙겨주는 돌봄 챗봇 GUI 프로그램입니다. \
향후에는 실제 돌봄 로봇과 결합하여 정서적 교감과 실질적 도움을 동시에 제공하는 통합 서비스를 목표로 개발했습니다.
- 사용자 감정 분석 기반 정서 케어 챗봇
- 표정·음성 인식, 자연어 처리, 일정 관리까지 GUI 통합 제공
- PyQt5 기반 데스크탑 앱 + GPT-4o-mini 스트리밍 응답 + DeepFace·Whisper 기반 감정 인식

## 담당 역할

- **설계 대상:** 팀장으로서 초기 프로젝트 구조, PyQt5 채팅 GUI, GPT-4o-mini 스트리밍 응답 처리, Whisper STT·gTTS 음성 경로, GUI와 서버 사이 TCP·UDP 통신
- **목적:** 표정·음성·제스처 감정 인식 결과와 대화 응답이 한 화면에서 끊기지 않고 실시간으로 이어지는 돌봄 챗봇
- **검증 방식:** 인터페이스 명세(로그인, 채팅, 감정 분석 결과, 영상·음성 스트림 등 10종)를 기준으로 모듈 사이 메시지를 맞추고, 팀원 모듈을 붙인 통합 시연으로 확인

| 파트 | 한 일 |
|:--|:--|
| 채팅 응답 | OpenAI Responses API 스트리밍 출력, 마크다운 응답 처리, 돌봄 상황 답변 시나리오와 학습 데이터 정제 |
| 음성 | Whisper.cpp(Large-v2) STT 연동과 실시간 음성 인식, gTTS 음성 안내 |
| 통신 | TCP·UDP 양방향 메시지 송수신, 채팅 UI 반응 속도를 위한 통신 정리 |
| 프로젝트 관리 | 초기 구조와 모듈 분담, `run.sh`로 팀원 로컬 실행 환경 통일, 리팩토링과 릴리즈 관리 |

음성 감정(CNN+LSTM), 얼굴 감정(ArcFace + MLP), 제스처 인식 모델은 팀원이 만들었고, 나는 이 모듈들이 GUI·통신 흐름에 붙는 순서를 조율했다. 모델 설명은 [StoneSpring README](https://github.com/mumallaeng/StoneSpring)에 있습니다.

### 기술 스택

| 분류 | 기술 요소 |
|------|-----------|
| **언어** | Python 3.12 |
| **데스크톱 UI** | PyQt5 |
| **대화 엔진** | OpenAI Responses API (GPT-4o-mini), python-dotenv |
| **음성 인터페이스** | whispercpp_kit (Whisper large-v2), PyAudio, gTTS, playsound |
| **비전·제스처** | OpenCV, Mediapipe, DeepFace(ArcFace) + scikit-learn MLP |
| **음성 감정 분석** | TensorFlow·Keras, librosa |
| **데이터베이스** | MySQL, mysql-connector-python |
| **인프라·통신** | Python socket TCP·UDP 서버 |
