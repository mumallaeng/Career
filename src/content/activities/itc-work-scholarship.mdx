인하공업전문대학 (인공지능빅데이터센터)[https://caid.inhatc.ac.kr/]에서 근로장학생으로 활동했습니다.

## 업무 개요
- **기간**: 2021년 9월 ~ 2022년 1월
- **기관**: 인하공업전문대학 인공지능빅데이터센터
- **역할**: 교내 근로장학생
- **담당**: 연구 및 인프라 지원

## 주요 업무 내용

### 연구 환경 지원
- **실험 환경 구축**: 연구 프로젝트에 필요한 개발 환경 설정
- **데이터 관리**: 연구용 데이터셋 정리 및 백업 관리
- **문헌 조사**: 연구 주제 관련 자료 수집 및 정리
- **실험 보조**: 연구 실험 진행 시 기술적 지원

### 인프라 운영 지원
- **시스템 모니터링**: 연구센터 내 컴퓨터 및 서버 상태 점검
- **하드웨어 관리**: 연구용 장비의 설치 및 유지보수 지원
- **네트워크 관리**: 센터 내 네트워크 환경 점검 및 문제 해결
- **백업 관리**: 중요 데이터 및 연구 자료의 정기적 백업

### 교육 프로그램 지원
- **실습 환경 준비**: 학생 대상 교육 프로그램의 실습 환경 구축
- **교육 자료 정리**: 강의 자료 및 실습 예제 정리
- **학생 지원**: 실습 과정에서 발생하는 기술적 문제 해결
- **장비 관리**: 교육용 하드웨어 및 소프트웨어 관리

### 행정 업무 지원
- **문서 작성**: 센터 운영 관련 각종 문서 작성 및 정리
- **일정 관리**: 연구 프로젝트 및 교육 프로그램 일정 조율
- **방문자 안내**: 센터 방문 외부 관계자 안내 및 지원
- **회의 준비**: 연구 회의 및 세미나 준비 작업

## 활용 기술 및 도구
- **시스템 관리**: Linux/Windows 서버 관리
- **개발 도구**: 다양한 개발 환경 구축 및 관리
- **데이터베이스**: 연구 데이터 관리를 위한 DB 운영
- **네트워크**: 기본적인 네트워크 설정 및 문제 해결

## 성과 및 경험
- **책임감**: 센터 운영에 필요한 중요 업무 담당을 통한 책임감 배양
- **문제 해결**: 다양한 기술적 이슈 해결을 통한 실무 경험 축적
- **커뮤니케이션**: 연구진 및 학생들과의 소통을 통한 협업 능력 개발
- **기술 이해**: 연구 환경에서 사용되는 다양한 기술 스택 경험

## 특별한 경험: 기술 세미나 기획
근로장학생 활동 중 가장 의미 있었던 경험은 
동아리 후배들을 위한 기술 세미나 **"서버를 써봐!"**를 기획하고 진행한 것입니다.

- **목표**: 서버 및 리눅스에 대한 접근성 향상

### 세미나 내용

- **실습**: MobaXterm을 활용한 리눅스 명령어 실습
- **Q&A**: 참가자 질의응답 및 토론

### 얻은 경험
- **교육 기획**: 교육 과정 전체를 설계하고 실행하는 경험
- **지식 전달**: 복잡한 기술 내용을 쉽게 설명하는 능력 개발
- **리더십**: 후배들을 이끌고 가르치는 리더십 경험
- **성취감**: 지식 공유를 통한 보람과 성취감 체험

이 경험은 단순한 업무 수행을 넘어서 
지식을 체계화하고 다른 사람에게 전달하는 능력의 중요성을 깨닫게 해주었으며, 
현재까지도 팀 프로젝트에서 지식 공유와

## 업무 개요
- **기간**: 2021년 8월 ~ 2022년 2월 (7개월)
- **기관**: 인하공업전문대학 인공지능빅데이터센터
- **역할**: 서버 및 인프라 운영 지원 / 세미나 기획 및 발표
- **주요 업무**: 서버 구축, 운영, 관리 전반

## 주요 업무 내용

### 서버 인프라 구축
- **Ubuntu Server 20.04 설치**: 베어메탈 서버에 운영체제 설치 및 초기 설정
- **네트워크 설정**: 서버 네트워크 환경 구성 및 외부 접속 설정
- **보안 설정**: 서버 보안 정책 수립 및 방화벽 설정
- **사용자 관리**: 다중 사용자 환경 구축 및 권한 관리

### 데이터베이스 서버 운영
- **MySQL 서버**: 연구용 데이터베이스 서버 구축 및 관리
- **Oracle 데이터베이스**: 대용량 데이터 처리를 위한 Oracle DB 운영
- **백업 자동화**: 정기적 데이터 백업을 위한 자동화 스크립트 작성 및 운영
- **성능 최적화**: 데이터베이스 쿼리 최적화 및 인덱스 관리

### 웹 서버 호스팅
- **Java Spring Boot**: Java 기반 웹 애플리케이션 서버
- **Node.js**: JavaScript 기반 웹 서비스 호스팅
- **외부 접속 구성**: 도메인 설정 및 SSL 인증서 적용
- **로드 밸런싱**: 트래픽 분산을 위한 서버 구성

### GPU 환경 구축
- **NVIDIA GPU 설정**: 딥러닝 연구를 위한 GPU 서버 구축
- **CUDA 설치**: NVIDIA CUDA 툴킷 설치 및 설정
- **드라이버 관리**: GPU 드라이버 설치 및 버전 관리
- **Docker GPU 지원**: GPU 가속을 지원하는 Docker 환경 구축

### 개발 환경 자동화
- **Git 연동**: 자동 배포를 위한 Git 훅 설정
- **CI/CD**: 지속적 통합 및 배포 파이프라인 구축
- **웹 애플리케이션 운영**: 개발부터 배포까지 전 과정 자동화
- **모니터링**: 서버 상태 및 애플리케이션 성능 모니터링

### 백업 및 복구 시스템
- **Clonezilla**: 시스템 전체 이미지 백업 및 복구 체계 구축
- **백업 전략**: 정기적 백업 스케줄링 및 백업 데이터 검증
- **재해 복구**: 장애 상황 대비 복구 절차 수립
- **데이터 무결성**: 백업 데이터의 무결성 검증 및 관리

### 멀티부팅 환경 구축
- **Windows + Ubuntu**: 듀얼 부팅 환경 구축
- **학내 PC 설정**: 연구 및 교육용 PC의 초기 설정
- **네트워크 구성**: 다양한 운영체제에서의 네트워크 환경 통합
- **사용자 가이드**: 멀티부팅 환경 사용법 문서화

## 활용 기술
- **운영체제**: Ubuntu Server 20.04, Windows Server
- **데이터베이스**: MySQL, Oracle
- **웹 서버**: Apache, Nginx
- **컨테이너**: Docker, Docker Compose
- **스크립팅**: Bash, Python

- **보안 강화**: 체계적인 보안 정책 수립으로 보안 사고 제로 달성
