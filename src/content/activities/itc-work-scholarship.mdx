인하공업전문대학 인공지능빅데이터센터에서 서버 인프라 구축 및 운영 업무를 담당했습니다.


## 업무 개요
- **기간**: 2021년 8월 ~ 2022년 2월 (7개월)
- **기관**: 인하공업전문대학 인공지능빅데이터센터
- **역할**: 서버 및 인프라 운영 지원 / 세미나 기획 및 발표
- **주요 업무**: 서버 구축, 운영, 관리 전반

## 주요 업무 내용

### 서버 인프라 구축
- **Ubuntu Server 20.04 설치**: 베어메탈 서버에 운영체제 설치 및 초기 설정
- **네트워크 설정**: 서버 네트워크 환경 구성 및 외부 접속 설정
- **보안 설정**: 서버 보안 정책 수립 및 방화벽 설정
- **사용자 관리**: 다중 사용자 환경 구축 및 권한 관리

### 데이터베이스 서버 운영
- **MySQL 서버**: 연구용 데이터베이스 서버 구축 및 관리
- **Oracle 데이터베이스**: 대용량 데이터 처리를 위한 Oracle DB 운영
- **백업 자동화**: 정기적 데이터 백업을 위한 자동화 스크립트 작성 및 운영
- **성능 최적화**: 데이터베이스 쿼리 최적화 및 인덱스 관리

### 웹 서버 호스팅
- **Java Spring Boot**: Java 기반 웹 애플리케이션 서버
- **Node.js**: JavaScript 기반 웹 서비스 호스팅
- **외부 접속 구성**: 도메인 설정 및 SSL 인증서 적용
- **로드 밸런싱**: 트래픽 분산을 위한 서버 구성

### GPU 환경 구축
- **NVIDIA GPU 설정**: 딥러닝 연구를 위한 GPU 서버 구축
- **CUDA 설치**: NVIDIA CUDA 툴킷 설치 및 설정
- **드라이버 관리**: GPU 드라이버 설치 및 버전 관리
- **Docker GPU 지원**: GPU 가속을 지원하는 Docker 환경 구축

### 개발 환경 자동화
- **Git 연동**: 자동 배포를 위한 Git 훅 설정
- **CI/CD**: 지속적 통합 및 배포 파이프라인 구축
- **웹 애플리케이션 운영**: 개발부터 배포까지 전 과정 자동화
- **모니터링**: 서버 상태 및 애플리케이션 성능 모니터링

### 백업 및 복구 시스템
- **Clonezilla**: 시스템 전체 이미지 백업 및 복구 체계 구축
- **백업 전략**: 정기적 백업 스케줄링 및 백업 데이터 검증
- **재해 복구**: 장애 상황 대비 복구 절차 수립
- **데이터 무결성**: 백업 데이터의 무결성 검증 및 관리

### 멀티부팅 환경 구축
- **Windows + Ubuntu**: 듀얼 부팅 환경 구축
- **학내 PC 설정**: 연구 및 교육용 PC의 초기 설정
- **네트워크 구성**: 다양한 운영체제에서의 네트워크 환경 통합
- **사용자 가이드**: 멀티부팅 환경 사용법 문서화

## 활용 기술
- **운영체제**: Ubuntu Server 20.04, Windows Server
- **데이터베이스**: MySQL, Oracle
- **웹 서버**: Apache, Nginx
- **컨테이너**: Docker, Docker Compose
- **스크립팅**: Bash, Python
- **모니터링**: Nagios, Grafana
- **백업**: Clonezilla, rsync

## 성과 및 경험
- **안정적 운영**: 7개월간 99% 이상의 서버 가동률 유지
- **효율성 향상**: 자동화 스크립트 도입으로 운영 효율성 대폭 개선
- **보안 강화**: 체계적인 보안 정책 수립으로 보안 사고 제로 달성
- **지식 전수**: 서버 운영 노하우를 후임자에게 체계적으로 전달
