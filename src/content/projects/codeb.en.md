Developed an AI education Python visual programming platform running on Pyodide-based WebAssembly execution environment.

<!--more-->

## Project Overview
- **Duration**: August 2021 ~ February 2022 (7 months)
- **Role**: Platform Maintenance and Educational Content Development
- **Goal**: Providing intuitive programming environment for AI/data science education

## Tech Stack
- **Core Technology**: Pyodide, WebAssembly
- **Languages**: Python, JavaScript
- **Libraries**: pandas, matplotlib, scikit-image, BioPython
- **Educational Tools**: Block coding, Visualization
- **Platform**: Web browser

## Key Responsibilities

### Library Block Implementation
- Implemented data science/AI library features (pandas, matplotlib, scikit-image, BioPython) in block form
- Abstracted complex library functionality into intuitive block interfaces

### Input/Output Block Feature Design
- Designed block functionality for handling various input/output sources (CSV, Pickle, PIL, URL)
- Implemented optimized data processing logic for each file format

### Educational Example Block Development
- Directly implemented educational example blocks including decision trees, similarity analysis, visualization graphs
- Added reusable functionality to improve learning efficiency

### User Experience Enhancement
- Resolved matplotlib Korean font rendering errors
- Restored legacy XML compatibility to improve user experience
- Built stable Python code execution environment in browser environment

## Key Achievements
- Built environment enabling Python AI/data science education with browser only
- Provided intuitive block-based interface accessible to coding beginners
- Developed scalable platform supporting various data formats and AI libraries
- Created practical examples and content usable in actual educational settings
