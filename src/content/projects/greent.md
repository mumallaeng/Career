IoT 센서와 자동화 시스템을 활용한 스마트 농업 효율 향상 시스템을 개발했습니다.

<!--more-->

## 프로젝트 개요
- **기간**: 2025.02.05 ~ 2025.02.27 (4주)
- **역할**: 시스템 컨트롤러 개발
- **목표**: 농업 자동화를 통한 효율성 증대

## 기술 스택
- **하드웨어**: Arduino, Raspberry Pi
- **센서**: 토양 수분 센서, RFID
- **액추에이터**: 워터 펌프, 스텝 모터
- **통신**: 시리얼 통신
- **백엔드**: Python Flask
- **카메라**: Raspberry Pi Camera

## 주요 담당 업무

### 센서 및 하드웨어 연동
- 아두이노, Raspberry Pi, 센서 연동을 통한 자동 급수, 출입 제어 시스템 개발
- 토양 수분 센서를 활용한 수분 감지 및 자동 워터 펌프 제어 기능 구현

### 영상 모니터링 시스템
- Raspberry Pi 카메라 영상 스트리밍 구현
- 스텝모터 기반 시야 조절 기능 개발

### 출입 관리 시스템
- RFID 인식 기반 출입 제어 기능을 시스템 제어 로직에 통합

### 백엔드 시스템 개발
- Python 기반 Flask 백엔드 구성
- 시리얼 통신을 통한 하드웨어와 소프트웨어 연동
- 시스템 컨트롤러와 GUI 연동을 위한 통신 시스템 개발

## 핵심 성과
- 자동 급수 시스템으로 물 사용량 최적화
- 실시간 농장 모니터링 및 원격 제어 시스템 구축
- RFID 기반 보안 시스템으로 농장 접근 관리 자동화
- 센서 데이터 기반 자동화된 농장 관리 시스템 구현
