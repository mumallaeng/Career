Java를 활용한 항공 예매 시스템을 개발하며 사용자 인터페이스와 예약 로직을 구현했습니다.

<!--more-->

## 프로젝트 개요
- **기간**: 2021.05.13 ~ 2021.07.15 (2개월)
- **역할**: 사용자 기능 개발 및 UI 구현
- **목표**: 완전한 항공 예매 시스템 구축

## 기술 스택
- **언어**: Java
- **GUI**: Java Swing/AWT
- **데이터베이스**: 관계형 데이터베이스
- **개발 도구**: Git, 협업 도구

## 주요 담당 업무

### 사용자 기능 구현
- Java 기반 로그인, 회원가입, 예약조회 등 항공 예매 전반 사용자 기능 구현
- 사용자 인증 및 세션 관리 시스템 개발

### 달력 UI 개발
- 탑승일 선택을 위한 달력(Calendar) UI 구성
- 날짜 선택/이동 기능 개발 및 사용자 친화적 인터페이스 제공

### 예약 시스템 로직
- 승객 수 선택, 출발지·도착지 설정, 예매 조건 분기 등 예약 조건 처리 로직 구현
- 복잡한 예약 조건을 처리하는 비즈니스 로직 설계

### 예외 처리 및 UI 개선
- 아이디/비밀번호 찾기 등 예외 상황 대응 UI 구성
- 각 폼의 레이아웃 개선으로 사용성 향상

### 협업 및 유지보수
- 브랜치 병합, 오류 수정, 주석 보완을 통한 유지보수성과 협업 효율성 향상
- 팀 개발 환경에서의 코드 품질 관리

## 핵심 성과
- 완성도 높은 GUI 기반 항공 예매 시스템 개발
- 직관적이고 사용자 친화적인 인터페이스 설계
- 복잡한 예약 로직을 안정적으로 처리하는 시스템 구현
- 팀 협업을 통한 대규모 프로젝트 경험 습득
