# 프로젝트 개요

Yeonwoo Space는 개인 브랜딩과 포트폴리오를 위한 통합 웹 생태계 구축 프로젝트입니다. GitHub Pages를 기반으로 여러 개의 독립적인 사이트를 구축하고, 각각의 목적에 맞는 콘텐츠를 제공하여 종합적인 개인 온라인 프레젠스를 구현하고 있습니다.

## 프로젝트 목표

- **통합된 개인 브랜딩**: 일관된 디자인 언어와 사용자 경험을 통한 강력한 개인 브랜드 구축
- **모듈화된 구조**: 각 프로젝트의 독립성을 유지하면서도 상호 연결된 생태계 구현
- **지속 가능한 관리**: 자동화된 배포와 콘텐츠 관리 시스템 구축
- **다국어 지원**: 한국어와 영어를 지원하는 글로벌 포트폴리오

# 구성 요소

## 1. yonmilk.github.io (메인 허브)
**URL**: [https://yonmilk.github.io](https://yonmilk.github.io)  
**상태**: 개발 진행 중

### 주요 기능
- 모든 프로젝트로의 중앙 진입점 역할
- 간결한 프로필 소개 및 링크 허브
- 미니멀한 디자인으로 빠른 네비게이션 제공
- 방문자 분석 및 통계 대시보드

### 기술 스택
- HTML5/CSS3/JavaScript
- GitHub Actions를 통한 자동 배포
- Google Analytics 4 연동

## 2. Space (기술 블로그)
**URL**: [https://yonmilk.github.io/space](https://yonmilk.github.io/space)  
**상태**: 기획 및 설계 단계

### 주요 기능
- 기술 관련 글 작성 및 공유
- 학습 노트 및 튜토리얼 제공
- 코드 스니펫 공유 기능
- 태그 및 카테고리 기반 콘텐츠 구조
- 댓글 및 피드백 시스템

### 계획된 콘텐츠
- 개발 경험 및 문제 해결 사례
- 새로운 기술 학습 기록
- 오픈소스 기여 경험
- 프로젝트 회고 및 포스트모템

### 기술 스택
- Jekyll 또는 Hugo (정적 사이트 생성기)
- Markdown 기반 콘텐츠 작성
- Utterances를 활용한 GitHub 이슈 기반 댓글
- RSS 피드 지원

## 3. Portfolio (포트폴리오 사이트)
**URL**: [https://yonmilk.github.io/portfolio](https://yonmilk.github.io/portfolio)  
**상태**: 활발히 개발 중

### 주요 기능
- 프로젝트 쇼케이스
- 경력 및 교육 이력 상세 소개
- 기술 스택 시각화
- 수상 내역 및 자격증 정보
- 연락처 및 소셜 미디어 링크

### 최근 업데이트
- Next.js 15.5 기반으로 전면 리팩토링
- 다국어 지원 (한국어/영어) 구현
- 반응형 디자인 최적화
- 마크다운 기반 콘텐츠 관리 시스템 구축
- 정적 사이트 생성(SSG)으로 성능 최적화

### 기술 스택
- Next.js 15.5 (App Router)
- TypeScript
- Tailwind CSS
- GitHub Actions CI/CD
- Vercel 또는 GitHub Pages 배포

# 프로젝트 의의

이 프로젝트는 단순한 포트폴리오 사이트를 넘어서, 개인의 전문성과 창의성을 종합적으로 표현하는 디지털 공간을 만드는 것을 목표로 합니다. 각 사이트는 독립적으로 운영되면서도 서로 유기적으로 연결되어, 방문자에게 일관되고 풍부한 경험을 제공합니다.

또한, 이 프로젝트 자체가 하나의 포트폴리오 아이템으로서 웹 개발 전반에 대한 이해와 실무 능력을 보여주는 증거가 됩니다. 지속적인 개선과 업데이트를 통해 최신 웹 기술 트렌드를 반영하고, 개인 브랜딩의 새로운 기준을 제시하고자 합니다.
