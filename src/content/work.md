이 페이지는 현재 activity archive에서 대표성이 높은 항목만 골라 public-facing summary로 연결한 curated work surface입니다. 전체 활동을 나열하기보다, 구현 방향과 읽는 목적이 비교적 분명한 항목만 먼저 묶었습니다.

## How to use this page

- 로보틱스와 시스템 통합을 먼저 보고 싶다면 `Shoepernoma`
- 음성/모델 연동이 있는 응용 프로젝트를 먼저 보고 싶다면 `StoneSpring`
- 자동화 도구와 처리 파이프라인을 먼저 보고 싶다면 `PDF to Question Bank`
- 교육 도구와 웹 기반 실행 환경 쪽을 먼저 보고 싶다면 `CodeB`

## Quick chooser

### If you want the most system-heavy project first

- start with `Shoepernoma`
- then compare it with `StoneSpring`
- use `Activities` if you need the deeper delivery history

### If you want application/product-style work first

- start with `StoneSpring`
- then move to `CodeB`
- use `Activities` if you want the supporting materials and context

### If you want smaller, tool-like implementation work first

- start with `PDF to Question Bank`
- then compare it with `CodeB`
- use `Activities` if you want the raw document trail

## Systems and robotics

### [Shoepernoma](/activities/shoepernoma)

매장 연동형 신발 피킹 로봇 시스템입니다. ROS2, Nav2, SLAM, ArUco, YOLOv8n, GUI 연동을 포함한 자동화 흐름을 팀 프로젝트로 구현했고, 팀장 역할을 맡았습니다.

왜 먼저 보기 좋은가:

- 시스템 구성 요소가 비교적 선명하게 드러납니다.
- 인식, 제어, GUI, 문서화가 한 프로젝트 안에서 연결됩니다.
- 팀 리딩과 구현을 같이 보여주기 좋습니다.

이 항목은 다음을 함께 보여줍니다.

- 로보틱스 시스템 통합
- 인식 및 제어 파이프라인 구성
- 문서와 구현을 함께 묶는 프로젝트 운영
- public reading focus:
  - robotics
  - autonomy pipeline
  - integration-heavy team project

## Applications and interaction

### [StoneSpring](/activities/stonespring)

실시간 상호작용을 목표로 한 돌봄 챗봇 GUI 프로젝트입니다. PyQt 기반 인터페이스, 음성 입출력, 감정 인식, GPT 기반 응답 흐름을 통합하는 작업을 팀장 역할로 진행했습니다.

왜 먼저 보기 좋은가:

- 모델 연동과 사용자 상호작용이 함께 보입니다.
- product-style application 흐름을 빠르게 파악할 수 있습니다.
- 팀 기반 기능 통합 경험을 읽기 좋습니다.

이 항목은 다음을 함께 보여줍니다.

- GUI 기반 응용 프로젝트
- 모델 연동과 실시간 인터랙션
- 팀 단위 기능 통합
- public reading focus:
  - AI-enabled application work
  - voice/interaction stack
  - product-style team delivery

## Tooling and automation

### [PDF to Question Bank](/activities/pdf-to-question-bank)

PDF 문제집을 문제 단위 이미지로 분해하는 CLI 자동화 도구입니다. 규칙 기반 이미지 처리로 문제 은행을 생성하는 흐름을 구현했습니다.

왜 먼저 보기 좋은가:

- 범위가 작아 끝까지 읽기 쉽습니다.
- 문서 처리 자동화 흐름이 비교적 명확합니다.
- 개인 도구 구현 스타일을 빠르게 파악할 수 있습니다.

이 항목은 다음을 함께 보여줍니다.

- 문서 처리 자동화
- CLI 중심 개인 도구 구현
- 작은 범위에서 끝까지 닫는 처리 파이프라인

### [AI 교육용 Python 블록 프로그래밍 웹 플랫폼](/activities/codeb)

교육용 블록 코딩 플랫폼 유지보수와 기능 개발에 참여한 프로젝트입니다. Pyodide, Blockly, 웹 기반 Python 실행 환경과 교육 현장 적용 경험이 함께 연결됩니다.

왜 먼저 보기 좋은가:

- 교육용 웹 도구 맥락이 분명합니다.
- 브라우저 기반 실행 환경과 현장 적용 경험이 함께 보입니다.
- 유지보수와 기능 개발이 함께 드러납니다.

이 항목은 다음을 함께 보여줍니다.

- 교육용 웹 도구 개발
- 브라우저 기반 실행 환경
- 기능 유지보수와 현장 적용 경험
